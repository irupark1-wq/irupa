# 동그란 사이 · 단계 A 로컬 시제품

저장소 루트에서 Node24로 `npm start`를 실행하거나 `게임1_테스트시작.cmd`를 실행한다. 브라우저에서 http://127.0.0.1:4173 에 접속한다. 처음 내려받은 코드라면 먼저 `node scripts/game1_build_prototype.mjs`로 browser core를 재생성한다. 종료는 터미널 Ctrl+C다.

화면은 전체 화면 게임이다. 방이 화면을 채우고 HUD(월드 명판·시계·속도)가 위에 뜬다. 하단 독 버튼(폰·기록·관계·폰 만들기·배치·방문·더보기)을 누르면 팝업 창이 뜬다. 폰을 누르면 상세 패널(데스크톱 오른쪽, 모바일 아래)이 열린다. 폰 만들기에서 빈 원에 파츠를 그리고 성격을 고른 다음 저장하고 월드에 배치하기를 누른다.

그림은 슬롯별 캔버스로 분리한다. 그리기25단계 undo 기록, 색/굵기/지우개/이동/크기/회전/숨기기와 눈·입 표시clip 비교를 구현했다. 시험 파츠는 보조 버튼으로만 불러온다. 실제 브라우저 입력/합성/undo 실기기 검증은 아직 통과 판정하지 않았다.

폰·성격·원장·구조·기억·receipt는 localStorage의 game1-local-a-v1 한 레코드에 저장한다. 초안은 game1-draft-v1에 따로 보관한다. 저장 실패는 committed 상태를 바꾸지 않고 초안을 보존한다. 브라우저 데이터를 삭제하거나 다른 브라우저를 사용하면 이 기록에 접근할 수 없으며 온라인 계정 복구 기능은 없다. 여러 탭의 순차 충돌은 감지하지만 동시 탭 쓰기 전체를 보장하는 서버/DB 잠금은 없다.

core/는 src/contracts의 TypeScript를 Node24 타입제거로 생성한 파일이다. 소스 수정 후 빌드를 다시 실행해야 한다. 기존 미추적 domain.js는 검토 후 채택하지 않았으며 app.js에서 사용하지 않는다. 원본은 삭제하지 않았다.

운영 서버/Auth/DB·외부 지급·알림·온라인 동의는 연결되지 않았다. UI의 승인/연결 옵션은 로컬 시나리오 입력이다. 로컬 소유 ID를 실제 계정 권한으로 사용해서는 안 된다. 관계 화면은 별도 공개 DTO로 변환하며 내부원장을 직접 전달하지 않는다.
