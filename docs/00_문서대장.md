# 《동그란 사이》 문서대장 (문서번호 규칙 + 목록)

관리: 김도현(Claude). 새 문서를 만들거나 받을 때마다 여기에 한 줄 추가한다. 팀원 간 대화는 **문서번호**로 한다(예: "PO-13 §12 의 A1 단계", "DEV-19 의 3절").

## 1. 번호 규칙

| 코드 | 작성자 → 받는 사람 | 뜻 | 파일 위치 |
|---|---|---|---|
| `PO-NN` | 김PO → 김도현(참조 팀원) | 기획서·세부계획서·결정서·게이트 판정 | `docs/planning/source/PO-NN_*.md` (받은 원본 그대로 보관) |
| `DEV-NN` | 김도현 → 김PO(참조 팀원) | 개발 계획·회신·납품 보고 | `docs/planning/DEV-NN_*.md` (2026-10-13 이전 회신은 `docs/planning/replies/NN_*.md` 가 그대로 DEV-NN) |
| `REQ-NN` | 김도현 → 김PO | 요청서: 세부계획서 요청, 김디자인·정연우에게 전달해 달라는 요청(규격·파일명·확장자 포함) | `docs/planning/requests/REQ-NN_*.md` |
| `DES-NN` | 김디자인 → (김PO 경유) 김도현 | 시안·자산·디자인 QA 수신 자료 | `docs/reference/design-*/` (수정 금지) |
| `REL-NN` | 정연우 → (김PO 경유) 김도현 | 관계 계약·검증 사례·검수 결과 | `docs/reference/rel-*/`, `yeonwoo-*/` (수정 금지) |
| `SB-NNNN` | 김도현 → 김PO | Supabase 에 입력할 SQL·함수·secret 안내 | `supabase/migrations/NNNN_*.sql`, `supabase/tests/`, `supabase/README.md` |

- 형식: `코드-번호_제목_v판.md`. 번호는 코드별 일련번호. 내용이 바뀌면 번호는 그대로 두고 판(v1.0 → v1.1)만 올린다.
- 한 문서는 한 가지 목적. 다른 문서 내용은 복사하지 않고 번호로 참조한다.
- 팀원 관리·전달은 김PO 가 한다. 김도현은 다른 팀원에게 직접 보내지 않고 `REQ-NN` 으로 김PO 에게 요청한다.
- 모든 문서 첫머리에 `문서번호 / 작성자 / 받는 사람 / 날짜 / 상태(초안·확정·완료)` 를 적는다.
