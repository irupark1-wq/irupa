# 2026-10-13 UI 전체 화면 게임형 재구성 (디자인 v1.0 시안 2장 기준, v2)

수신 시안 10_03_42-2 / 10_03_45-3 의 구조를 따르되, PO 의 추가 요청(전체 화면·팝업 창·게임형 버튼)에 맞춰 프런트엔드 4개 파일을 다시 썼습니다. 저장 구조·시뮬레이션·관계 원장·서버·CSP 는 손대지 않았습니다.

## 구조

- **전체 화면 장면**: `.game` 이 뷰포트를 꽉 채우고 스크롤이 없습니다. `life-ui.js` 의 `frameScene()` 이 배경 그림 안의 바닥 영역(`FLOOR` 비율)이 HUD 와 독 사이에 들어오도록 배율·위치를 계산해 배경(`transform`)과 12×8 바닥(`#lifeStage`)을 px 로 놓습니다. 창 크기가 바뀌면 `ResizeObserver` 로 다시 계산합니다. 배경보다 화면이 크면 흐린 배경(`.scene-blur`)이 바깥을 채우고 방에 테두리(`.diorama`)를 줍니다.
- **HUD**: 왼쪽 위 월드 명판(로고·내 월드), 오른쪽 위 시계(Day·시각·해/달)·일시정지·×1 ×2 ×4.
- **하단 독**: 폰 / 기록 / 관계 / 폰 만들기(큰 주황 버튼) / 배치 / 방문 / 더보기. 각 버튼은 팝업(`.sheet`)을 엽니다. 데스크톱은 가운데 카드, 모바일은 바텀시트. 배경 클릭·× 버튼·Esc 로 닫힙니다.
- **폰 상세 패널**: 폰을 누르면 열립니다(데스크톱 오른쪽 떠 있는 패널, 모바일 독 위 바텀시트). 탭: 현재 상태 / 관계 요약 / 기억 / 성격 / 상세 정보. 다른 폰으로 전환 아바타 줄 포함.
- **전체 창(`.screen`)**: 폰 만들기, 성격, 관계와 기억, 공방 시험(보존), 공간 표현 비교. 왼쪽 위 둥근 뒤로 버튼으로 월드로 돌아옵니다.
- **게임 버튼**: `.gbtn`(3D 알약, 아래 그림자·눌림 애니메이션), `.plate`(명판), `.dock-btn`(색 원형 아이콘 버튼).

## 유지한 것

- 모든 초상은 사용자가 그린 6개 파츠로만 합성. 시안 얼굴 고정 삽입 없음.
- 로컬 저장 키 `game1-local-a-v1`, 초안 키, 명령 ID 재시도, 버전 충돌 처리, 방문 대역 권한 범위, 보존된 공방 시험(더보기 안).
- 서버 CSP `style-src 'self'` 유지. 인라인 `style=` 속성 없이 JS `element.style` 만 사용.

## 데이터 ↔ 화면

- 시계 `08:00 Day 1` = tick 0. 1 tick = 1분. 06시 전·19시 후 달 아이콘.
- 필요 막대: 휴식 = 100-tired, 활동 = activity, 사회 = social. 시안의 "만족감"은 시뮬레이션 값이 없어 미표시.
- 현재 행동 진행 막대: `actor.started`~`actor.until`.
- 관계 변화 팝업: `life.logs` 중 `changes` 가 있는 마지막 기록의 애정/신뢰 증감 + 내 폰 전체의 본인 방향 관계 목록.

## 검증

- `npm test` 114개 통과, `node --check` 통과, HTML id ↔ JS 참조 전수 대조(누락 0).
- 브라우저 1440×900: 장면이 화면을 채우고 HUD·독·상세 패널이 떠 있음. 팝업 5종 열고 닫기, 배치 모드 격자·트레이, 폰 전환 확인. 콘솔 오류 0.

- secrets 검사 스크립트는 이 환경에 Python 이 없어 실행하지 못했습니다. 비밀값을 추가한 파일은 없습니다.
