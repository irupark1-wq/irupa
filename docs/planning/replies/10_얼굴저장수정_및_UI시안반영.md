# 얼굴 수정 저장 오류 및 시안 반영 UI 개선

2026-10-13 / 김도현

## 수정 내용

기존 앱에는 기존 폰의 얼굴을 수정하는 진입점과 저장 API가 없었습니다. 새 폰 생성 또는 성격만 저장하던 흐름을 고쳐, 월드의 `얼굴 꾸미기`에서 저장된 6개 파츠를 불러오고 같은 폰 ID의 외형을 갱신합니다. 얼굴 저장은 기존 관계·기억·공방 기록을 유지합니다. 성격 변경이 없으면 과거 성격 버전도 유지합니다.

편집기에 `저장하기`를 추가했습니다. 수정 대상 ID를 초안에 함께 보관하여 실패 후 새로고침해도 같은 폰에 다시 저장합니다. 저장 중 중복 클릭을 막고 실패 후 선택을 바꾸면 새 명령으로 저장합니다. 실패 후 동일 내용 재시도도 지원합니다.

보내주신 3개 시안에 맞춰 크림색 패널, 파란 주요 버튼, 도구 레일·큰 캔버스·레이어 패널, 색상 팔레트와 접는 세부 설정을 적용했습니다. 월드는 목재·식물·창문이 있는 일러스트 공간에 실제 사용자 폰을 합성합니다. 관계·성격·공방 화면에도 같은 색상과 패널 스타일을 적용했습니다. 시안의 전체 콘텐츠와 온라인 기능까지 구현했다는 의미는 아닙니다.

## 검증

- 자동 시험 99개 통과: 기존 97개와 외형 수정·재접속·실패 원자성·동일 명령 재시도 회귀 2개.
- 실제 브라우저: 기존 밤의 입 그리기 → 저장 → 새로고침 → 얼굴 편집에서 그림 유지 확인.
- 실제 브라우저: 저장 실패 재현 → 새로고침 → 같은 폰의 초안 복구 → 저장 성공, 폰 3명 유지.
- `node --check prototype/app.js` 및 시크릿 검사 수행.
- 배경은 표시 전용입니다. PNG 파츠 및 로컬 기록과 독립되어 있습니다. 온라인 인증·운영 DB 변경은 없습니다.

## 사용법

실행 파일: `C:\code\game\게임1_테스트시작.cmd`. 접속 주소: http://127.0.0.1:4173 . 이미 열려 있으면 새로고침합니다.

내 월드 → 해당 폰의 얼굴 꾸미기 → 그림 수정 → 저장하기 순서입니다. 성격 화면으로 이동해 저장해도 같은 폰에 반영합니다.
