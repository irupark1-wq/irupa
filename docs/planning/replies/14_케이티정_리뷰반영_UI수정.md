# 2026-10-13 케이티정 리뷰 반영 · UI 수정 기록

케이티정(디자인 디렉터 역할) 문서의 《동그란 사이》 원칙과 특별 리뷰 질문을 v2 UI 에 대조해 수정했습니다. 형식은 케이티정의 비평 단위(문제 → 원인 → 수정 → 검증)를 따릅니다.

## 디자인 판단

v2 는 "전체 화면 게임"이라는 틀은 맞췄지만, **창작을 시작하게 만드는 힘**과 **관계를 장면으로 느끼게 하는 장치**가 약했습니다. 이번 수정은 그림을 새로 그리지 않고 코드로 가능한 범위에서 그 둘을 보강했습니다.

## 잘된 점 (유지)

- 폰 몸체가 빈 원이고, 모든 초상이 플레이어 그림으로만 합성된다(원칙 1·2).
- 배경·UI 가 파스텔 저채도라 검은 선 얼굴이 읽힌다(원칙 4).
- 현재 행동에 "왜"(reason)와 남은 시간이 붙어 자율 행동이 답답하지 않다(리뷰 질문 3).

## 바린 대안

- **A. 기본 얼굴 제공**: 그리기 장벽은 낮지만 원칙 2·5 와 정면 충돌 → 폐기.
- **B. 튜토리얼 팝업 3장**: 창작 공간보다 UI 가 커짐(리뷰 질문 5) → 폐기. 점선 안내로 대체.
- **C. 관계 수치를 숨기고 문장만**: 관계 담당(정연우)의 검증 UI 가 수치를 쓰므로 팝업 안 수치는 유지, 장면에서는 이펙트만 → 채택.

## 검증 결과

- `npm test` 114개 통과, `node --check` 통과, HTML id ↔ JS 참조 누락 0.
- 브라우저: 빈 저장소에서 시작 → 점선 안내 표시 → 첫 획 후 사라짐 확인. ×4 로 돌려 관계 변화 이펙트 발생 확인(아래 수치는 실행 로그 참고).
- 사용자 테스트(30초 내 첫 획, 예시 사용 비율)는 **아직 하지 않았습니다**. 위 표의 효과는 가설입니다.

## Design Learning Log

- 사용자 문제: 그릴 이유를 못 찾고 예시를 눌러 버리는 것.
- 처음 세운 가설: 전체 화면·게임 버튼이면 충분하다.
- 최종 선택과 이유: 창작 유도(점선)와 관계 이펙트가 "게임 느낌"의 본체였다.
- 버린 대안과 이유: 기본 얼굴, 튜토리얼 팝업(위 참조).
- 검증 전 가설: 점선 안내가 첫 획 시간을 줄인다.
- 다음에 재사용할 규칙: 보조 기능은 주 기능과 같은 크기의 버튼으로 두지 않는다.
