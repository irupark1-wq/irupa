# 김도현: 2026-10-13 윤디자인 UI 시안 적용

수신 이미지 10_03_42-2 / 10_03_45-3을 폰 상세·최근 행동/기억·로컬 방문 화면의 제작 기준으로 반영했습니다. 원본은 docs/reference/design-20261013에 보존했습니다.

- 큰 원형 초상, 말풍선·이전/다음 폰, 파란 이름/행동 헤더, 실제 욕구 퍼센트 막대, 메모 카드, 얼굴 편집/관계 이동, 자기 방향 관계 요약을 연결했습니다.
- 기록은 시각과 행동 아이콘·이름 칩·내용으로 나누고 전체 기록 버튼으로 현재 보존된 최대 120개를 펼칩니다. 실제 알려진 최근 기억만 헤더에 표시합니다.
- 방문은 상태/그림 영역과 4개 버튼, 중립적인 단절 안내, 권한 보증 문구로 재구성했습니다. 실제 온라인이 아닌 로컬 대역 라벨을 유지합니다. 권한이 철회된 방문 대역은 초상 묶음에서도 제외합니다.
- 사용자 그림 원본으로 모든 초상을 합성합니다. 시안의 예시 얼굴/645초/62%/92% 등을 고정 데이터로 넣지 않았습니다. 배경은 기존 실행용 방 일러스트를 사용하며 수신 완성 시안 이미지를 버튼 위에 붙이지 않습니다.
- 기존 자동 생활 월드는 상세 패널 위에서 유지합니다. 편집기·저장·관계 계약·보안 범위는 동일하며 서버 설정을 변경하지 않았습니다.

검증: 114개 기존 계약/저장/자율 생활 회귀 검사, 비밀값 검사, 문법/공백 검사 통과. 브라우저에서 폰 전환, 관계 방향 이동, 기존 얼굴 편집 연결, 120개 기록 펼치기 및 390px 가로 넘침 없음(문서 폭 375px)을 확인했습니다. 재실행 후 기존 645tick 정지 상태와 관계를 복구했으며 콘솔 오류 0건입니다. idle 상태에서는 이전 작업의 오래된 reason을 이름 헤더에 붙이지 않습니다.

실행 증거: docs/evidence/game1-design-ui-20261013.png. 기존 온라인 방문·배치 전 통로 미리보기·신규 갈등 생성 게이트는 이전 회신의 남은 범위를 유지합니다.
