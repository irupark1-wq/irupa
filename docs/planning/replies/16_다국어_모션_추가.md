# 2026-10-13 다국어(ko·en·ja) + 모션 연출 추가

## 다국어

- `prototype/i18n.js` 하나로 처리합니다. **사전의 키는 한국어 원문**(gettext 방식)이라 코드의 한국어 문자열이 곧 키입니다. 한국어는 사전이 필요 없고, 영어·일본어 사전만 있습니다.
- 기본 언어는 한국어. 처음 켤 때 `navigator.languages` 에서 ko/en/ja 를 찾고, 없으면 한국어. 더보기 → 언어에서 바꾸면 `localStorage(game1-lang)` 에 저장하고 새로고침합니다(모든 문자열이 로드 시점에 고정되므로 새로고침이 가장 단순하고 안전).
- 적용 범위: HTML 정적 글자(텍스트 노드·placeholder·aria-label·title·alt, `applyStatic()`), `app.js`·`life-ui.js` 의 모든 한국어 리터럴(`T("…")` 206곳), 시뮬레이션이 저장한 문장(`tLife()`: "포근한 쉼터로 가요" 같은 장소 이름+어미 합성문을 분해해 번역), 문서 제목·`<html lang>`.
- 이름은 번역하지 않습니다. 사전에 있는 이름(루미·노을·모래·밤)만 바뀝니다.
- 제목 명판은 언어별 그림(`brand/title-en.png` Little Circles, `brand/title-ja.png` まるい縁)을 씁니다. 디자이너가 검은 배경 WebP 로 보내서 검은색 flood-fill 로 투명화해 넣었습니다(`docs/reference/design-20261013-d/09·10`). 없으면 한국어 명판으로 대체.
- **새 문구를 추가할 때 규칙:** JS 에서는 `T("한국어")`, 변수가 있으면 `T("{name}의 …", { name })`. 그리고 `i18n.js` 의 en·ja 사전에 같은 키를 추가. 빠진 키는 브라우저 콘솔에서 `(await import('/i18n.js')).missingKeys()` 로 확인.
- 언어 추가: `DICT` 에 코드와 사전을 더하고 `LANGS` 에 표시 이름을 적으면 더보기에 버튼이 생깁니다.

## 모션 연출 (`prototype/fx.css` + `life-ui.js` 의 fx 블록)

참고 영상(종이 질감 손그림 모션그래픽)에서 가져온 것: 통통 튀는 등장, 마커로 긋는 강조, 가벼운 입자.

| 연출 | 트리거 | 구현 |
|---|---|---|
| 시간대 색조 | 게임 시각(새벽/낮/해질녘/밤) | `.tod` 막 + 밤·해질녘에 창문·램프 자리 빛(`.glow`) |
| 햇살 먼지 | 항상 | `.mote` 14개, 랜덤 경로 |
| 발걸음 먼지·착지 | 폰이 칸을 옮길 때 / 이동을 멈출 때 | `.puff`, `.land`(스쿼시·스트레치) |
| 떠오르는 그림 | 쉼(z), 대화(♪·하트), 작업(✦) 중 확률적으로 | `.float` |
| Day 배너 | 날이 바뀔 때 | `.day-banner`, 마커 긋기 애니메이션 |
| 기록 알림 점 | 기록 팝업이 닫혀 있을 때 새 기록 | 독 "기록" 버튼의 `.dot` |
| 버튼 통통 | 독 버튼 누름 | `.bump` |
| 팝업·패널·말풍선 등장 | 열릴 때 | 종이가 튀어나오듯 스프링 |
| 시계 틱 | 분이 바뀔 때 | `.tick` |

`prefers-reduced-motion` 이면 모두 꺼집니다(기존 전역 규칙).
