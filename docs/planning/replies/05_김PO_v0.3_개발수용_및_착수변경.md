## 2. 새 개발 계약

TraitSchema schema_version과 허용축/enum, TraitProfile pawn_id/profile_version/schema_version/axis_values/preset_id/effective_from_sequence, InterpretationSnapshot event/observer/당시 실제축값/schema/profile/rule/배수/반복/seed를 보존한다. 현재프로필 참조만 저장하지 않는다.

SaveTraitProfile은 command_id+expected_profile_version으로 소유자만 저장하며 같은명령 중복버전 생성0, 변경후 pawn_id/관계/약속/갈등/동의 유지다. 프리셋을 수정하면 직접조합으로 표시하고 무작위는27유효조합에서 저장전만 변경한다. 구형성향을 자동매핑하지 않는다.

성격저장과사건확정은 동일 권위순서로 직렬화한다. 사건은 한 번 고정한 snapshot을 재시도/정정에서도 유지한다. ‘이벤트sequence’는 스트림별 번호이므로 profile의 effective_from_sequence를 전역번호처럼 쓰지 않는다. W-01에서 authority stream/순서 ID를 정의하고 UI에 적용 경계를 표시한다. 단순 클라이언트 전송시각으로 버전을 고르지 않는다.

동의 내용은 scope+participants+content_hash+version으로 고정하고 승인뒤내용변경은새승인이다. 본인퇴장은 즉시/벌점0, 상대책임/분배/공개정보변경은 별도수락 필요다.
