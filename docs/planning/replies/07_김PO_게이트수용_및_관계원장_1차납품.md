# 김도현 → 김PO·정연우·김디자인: G-A-REL 1차 납품

2026-10-13. 기준: 김PO `07_김PO_팀원통합회신_검토및다음게이트.md`, 정연우 검토/다음개발요청 v0.4.1, 디자인 회신/상태인계 v0.6. 원본 5개 및 정정된 PO07을 변경 없이 `docs/reference/review-v061/`에 보존했다.

처음 김PO 폴더에서 받은 06은 개발자의 기존 통합 회신과 파일 해시까지 동일했다. 새로운 PO 판단으로 취급하지 않았으며 이번 PO07을 최신 게이트 기준으로 적용한다. 첨부 문서의 담당자 의견과 사용자 직접 지시는 구분한다. 다른 담당자의 채팅으로 실제 발송하지 않았다.

원장은 사건 당시 observer snapshot·rule_version·seed·repeat_multiplier를 보존한다. 동일 지연의 사유 정정은 원 source 슬롯 하나의 knowledge revision을 교체하고 checkpoint부터 authority 순으로 재생한다. 같은 revision·correction_id 재전송은 중복 적용하지 않고, 동일 ID에 다른 payload는 오류로 거절한다. 다른 stream 비교, checkpoint 이전 사건, 순번 충돌, revision 누락도 거절한다. 잘못된 append에서 기존 상태는 바뀌지 않는다.

EVT08은 독립 action_id, EVT10은 독점 증거, EVT09는 정정·전달 완료, EVT12는 정확한 conflict/topic/scope 및 repair_plan_id·실행·수용 근거를 요구한다. EVT09/12는 같은 action_id를 긍정 기여에 재사용할 수 없다. 근거 필드는 시험 입력의 가정이며 실제 증거의 진위나 사용자 승인을 검증하는 서버는 아직 없다.

## 검증 범위와 제한

`npm test`: Node v24.19.0, 총 20개 통과/0개 실패. `node scripts/game1_run_ledger_fixture.mjs`로 입력 fixture의 실행 trace를 생성했다. `python scripts/game1_check_secrets.py` 통과. 실행 로그와 JSON에 당시 환경 및 before/contribution/after, 방향, snapshot, revision, 중복 status를 기록한다. CI 실행 명령도 npm test로 갱신했다. 원격 CI 결과는 미확인이다.

TypeScript 정적 타입검사는 미구성이다. 현재 Node24의 타입 제거로 실행되는 의존성 없는 시험 모듈이며, 실행 검사는 정적 타입검사를 대신하지 않는다. 통합 서비스·DB transaction·동시성·Auth/권한·outbox 검증과 배포는 수행하지 않았다.

1. ResourceLink/DecisionRole/acceptedCommitment/Conflict 입력으로 파생4축 재산출과 무근거 권력500 basis를 검증한다. 근거 없는 power520/550은 사용하지 않는다.

3. 공방 27명목경로의 비용·승인·인지·대안·중단·결말을 검증한다. 기본 성격과 대표 고/저 교차사례를 추가하며 성격27조합과 시험군을 분리한다. 이번 단계에 전체729를 필수로 확대하지 않는다.
4. CreatePawn 상태 fixture, 관계 projection, 공방 DTO를 디자인에 납품한다. GetTraitOptions는 이번에 축/단계 순서·문자열키·6안정프리셋ID와 실제 axis_values를 제공했다. 문자열키는 번역표와 화면 연결이 필요하다.

eyes/mouth의 display_clip은 여전히 미결이며 어느 쪽도 기본 강제정책으로 구현하지 않았다. input_clip=none·base 정원/균일scale·장식돌출은 유지한다. 디자인 문서의 반지름192px는 잠정 실험 규격이며 최종 자산 확정으로 승격하지 않는다. 실제 시안·파츠·클릭UI는 이번 첨부에 없었다.

계획/단위검증/통합검증/배포 상태를 계속 구분한다. 이번에는 운영 DB/Auth/배포를 변경하지 않았다.
