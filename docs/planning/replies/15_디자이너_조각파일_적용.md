# 2026-10-13 디자이너 조각 파일 적용 (스킨 v1)

디자이너가 보낸 8장(`docs/reference/design-20261013-d/`, 배경 2장 + 투명 WebP 스프라이트 시트 6장)을 잘라 게임에 입혔습니다. 승인 시안(`design-20261013-c`)과 같은 룩이 됐습니다.

## 자르기

- 시트는 이미 투명 배경(알파)이었습니다. 알파 ≥160 픽셀을 8방향으로 묶어 연결 성분을 찾고, 읽는 순서(위→아래, 왼→오른쪽)로 이름을 붙여 PNG 65장으로 내보냈습니다. 조각난 아이콘(감은 눈+zzz, 번개+빛)은 합쳤고, 망치·망치자루가 붙은 것은 수동 좌표로 잘랐습니다.
- 도구: `sharp`(스크래치패드에만 설치, 레포 의존성 아님). 스크립트는 레포 밖에 두었습니다. 재작업이 필요하면 같은 방식으로 다시 자르면 됩니다.
- 배경 2장은 WebP → PNG 변환만(1672×941, 941×1672).
- 결과: `prototype/assets/` 아래 `background/ brand/ bubbles/ furniture/ log/ needs/ relation/ ui/(dock, hud, icon)`.

## 입힌 곳

| 화면 요소 | 파일 | 방식 |
|---|---|---|
| 배경(가로/세로) | `background/room-landscape.png`, `room-portrait.png` | 무대와 같은 비율이라 그대로 덮음(`frameScene` 분기). 빈 마루 비율은 `life-ui.js` `BACKGROUNDS` |
| 상단 명판·시계·속도 | `brand/title.png`, `ui/hud/plate.png`, `sun/moon/pause/play.png`, `ui/tab-on/off.png` | 명판·속도는 9-slice(`border-image`) |
| 하단 독 | `ui/dock/bar.png` + 아이콘 7개 | 나무 판은 9-slice, 아이콘은 `<img>`, 폰 만들기는 파란 링 |
| 활동 지점·장애물 | `furniture/*.png`, `ui/label.png` | 매트 그림 + 이름표 9-slice |
| 폰 말풍선 | `ui/bubble.png`(글 풍선, 9-slice) + `bubbles/*.png`(행동 아이콘 풍선) | 듣기→대화, 보완 듣기→보완 아이콘으로 매핑 |
| 폰 상세 패널·팝업 | `ui/panel.png`(9-slice), `ui/tab-on/off.png`, `ui/icon/tab-*.png`, `needs/*.png`, `ui/icon/wand, book-open, close.png`, `ui/avatar-ring.png` | 탭은 시안대로 3개(현재 상태·관계 요약·기억). 성격은 현재 상태 아래로 |
| 기록·관계·방문·더보기 팝업 | `log/*.png`, `relation/*.png`, `ui/visit-header.png`, `ui/icon/door, exit, link-off, refresh, cloud-up, folder, compare, hammer, gear.png` | |

스킨은 `prototype/skin.css` 한 파일에 모았습니다(`style.css`/`world-design.css` 다음에 로드). 디자이너 그림을 빼면 이전 코드 그림으로 돌아갑니다.

## 검증

- `npm test` 114개 통과, `node --check` 통과, 이미지 404 없음(모든 `<img>` naturalWidth > 0).
- PC 1440×900 가로: 승인 시안 01과 같은 배치 확인(`docs/evidence/game1-ui-v6-skin-landscape.jpg`), 방문·기록 팝업(`-visit.jpg`, `-journal.jpg`).
- 폰 375×812 세로: 세로 배경 적용, 가로 넘침 없음(`-portrait.jpg`). 좁은 폰에서는 ×4 버튼을 숨김.
