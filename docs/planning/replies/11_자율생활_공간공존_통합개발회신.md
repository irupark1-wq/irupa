# 김도현 → 김PO·정연우·윤디자인: 자율 생활 구현 회신

2026-10-13 / 로컬 단계 A 실행본 / 전체 제작 및 온라인 게이트 미완료

## 수신 및 적용 기준

김PO 11 방향수정 지시, 윤디자인 「포근한 폰 라이프심 게임 UI 설계도」와 새 패키지 v1.0, 연우.zip의 v0.6 문서 3개·JSON을 모두 읽었습니다. 원본은 docs/reference/po-v11, design-v10, yeonwoo-v06에 보존했습니다. 수신 문서는 제작 참고·검토 기준이며 배포 권한이나 테스트 통과 기록으로 취급하지 않았습니다. 연우 JSON은 본문의 18개 설명과 달리 AUTO-01~22 총 22개이며 design_only_not_executed / production_import_allowed=false를 변경하지 않았습니다.

## 실행 가능한 변경

- 내 폰 3명이 대화 버튼 선택 없이 이동·휴식·작업·접근·거절·수락·대화·도움을 수행합니다. 성격 3축은 후보 가중치에 반영하고, 관계·현재 욕구·점유 상태가 상대 반응을 결정합니다. 높은 애정도 수락을 강제하지 않습니다.
- 월드에서 폰을 선택하면 현재 행동, 표면상 이유, 필요, 본인 방향 관계 요약, 인지한 최근 기억을 확인합니다. 전체 8축·기억 화면으로 연결하며 상세 패널을 접을 수 있습니다.
- 쉼터·작업대·이야기 자리 이동/닫기와 장애물 변경이 실제 경로에 적용됩니다. 막힘·대상 이탈은 완료 사건이 되지 않습니다.
- 생활 일시정지, ×1/×2/×4, 상태 저장·복구를 연결했습니다. 재실행 시 기존 생활을 정지 상태로 복구하고 오프라인 시간을 보상이나 사건으로 소급하지 않습니다.
- 루미 로컬 방문 대역은 같은 공간에 참여하지만 소유 폰 목록에 추가되지 않습니다. 호스트 공간 허용과 소유자 참여·가벼운 사건 허용을 분리합니다. 퇴장·단절·허용 철회는 벌점 0이며 방문 폰의 필요·성격·반대 방향 관계는 화면에 표시하지 않습니다.
- 기존 6슬롯 원본·transform·원형 베이스를 계속 사용합니다. 얼굴 수정은 같은 폰 ID의 외형 버전을 갱신하므로 관계와 기억을 유지합니다.
- 수동 3라운드 공방은 주요 화면 흐름에서 제외했습니다. 기존 27경로 계약·원장 테스트는 회귀 검사용으로 보존합니다.

## 정연우 기술 질문 회신

1. 로컬 authority는 store의 한 commit입니다. tick 진행·좌표·확정 사건·기억·중복 제한을 복사본에 적용하고 저장 성공 후 교체합니다. 여러 탭은 변경 감지 시 진행을 멈추며 서버 수준 CAS는 아닙니다.
2. 후보 선택 → 이동 → 상대 반응/수락 → timed 실행 완료 → 원장 확정을 분리했습니다. 길막/피로/대상 이탈은 중립 취소입니다. 같은 seed·상태·맵은 동일 결과로 재생됩니다.
3. 단순 인접은 0효과입니다. 인사 완료는 EVT-01 애정 +4만, 실제 수락한 도움 완료는 EVT-04를 사용합니다. 쌍별 대기 60tick·종류별 누적 3회 상한은 단계 A 시험 규칙이며 최종 밸런스가 아닙니다. 낮은 공정성을 공로 누락으로 해석하지 않습니다.
4. 과거 원장·8축·snapshot·태그·기억 투영을 재사용합니다. 기존의 명확한 갈등과 정정 기록이 있을 때만 정확한 scope/topic/conflict를 대상으로 수락·실행된 EVT-12 보완을 확정합니다. 다른 갈등을 함께 지우지 않고 기억을 유지합니다.
5. seed 및 내부 후보 trace는 로컬 검사 자료입니다. 화면에는 허용된 행동/기억만 표시합니다. 사건 지식 수정은 원래 슬롯을 바꾸어 재투영하며 행동이나 보상을 다시 실행하지 않습니다. 태그 이력 전체 재구축 QA는 별도 남아 있습니다.

새 월드에서 약속·기한·영향·독립적 공로 증거를 자동 생성하는 기능은 아직 없습니다. 따라서 새로운 EVT-07/08/09/10 갈등 서사 전체가 구현됐다고 보고하지 않습니다. 기존 시험 갈등의 보완 동작은 실행 검증했습니다. 낮은 신뢰·높은 존중 협업 및 갈등 중 협력의 확장 조건도 추가 계약·검사가 필요합니다.

## 검증과 남은 게이트

Node 로컬 테스트 총 114개 통과(실패 0). 신규 자율 생활 검사 15개는 350tick 이동·휴식·인사·도움, 동일 seed 재생, UUID 길이, 성격별 후보 차이, 반응 거절, 점유/BFS, 활동 지점 폐쇄, 일시정지/복구, 저장 실패 원자성, 반복 상한, 대상 이탈, 방문 권한 철회·개인정보, 지식 수정, 경계 좌표, 기존 정확한 갈등 보완을 포함합니다. 기존 99개는 얼굴 저장 및 계약 회귀 검사입니다. 받은 22개 설계 사례를 그대로 전부 실행한 결과와는 다릅니다.

브라우저에서 ×4 자율 진행, 직접 선택 없는 도움/인사 완료, 방문 상세의 비공개 정보 제외, 단절 중립 표시, 222tick 일시정지, 작업대 좌표 (8,3) 저장을 확인했습니다. 브라우저 증거는 docs/evidence/game1-autonomy-world.png입니다.

## 2D/3D 및 다음 제작 순서

2D를 현재 제작 기준으로 권고합니다. 「공간 표현 비교」에서 현재 같은 폰 원본/좌표/활동 지점을 투영한 3D 기하 공간과 2D 폰 빌보드를 확인할 수 있습니다. 이는 Canvas 소프트웨어 투영 기술 비교이며 최종 3D 엔진, 전체 가림/조명, 같은 조건의 성능 비교 완료본은 아닙니다. 디자인 패키지의 비교 이미지는 참고 시안으로 보존합니다. 배경 그림에 그려진 가구는 장식이며 실제 길찾기는 표시된 활동 지점·장애물 grid를 사용합니다.

다음 순서: (1) 디자인과 grid/그림 가구 위치 합의 및 배치 미리보기 1~2일, (2) 정확한 약속/공로 증거 기반 갈등 생성과 협력 확장 2~3일, (3) 22관계·14디자인 전수 실행 증거 및 크기/가림 QA 1~2일. 담당 1명 기준 예상이며 검토 회신에 따라 조정합니다.

실제 온라인은 별도 5~10 작업일 예상: game1 참여/소유권/JWT·RLS 1~2일, 호스트 서버 시계/트랜잭션/재전송 방지 2~3일, 초대·공개 스냅샷·권한별 Realtime·단절 복구 1~3일, 타인·다른 게임·거부/동시성 QA 1~2일. Supabase Auth/DB/Edge 배포는 이번 범위에서 변경하지 않았습니다. 로컬 대역 화면은 실제 서비스 권한 보안을 증명하지 않습니다.

김디자인 요청: 실제 12×8 활동 위치와 맞는 배경/가구 분리 자산, 6슬롯 48/64/96px 읽힘 검수, 배치 전 유효/막힘/취소 화면, 방문/정지/저장실패 구분 시안을 부탁드립니다. 현재 새 패키지에는 추가 실행용 6슬롯 PNG가 없어 기존 원본을 유지했습니다.

김PO 결정 요청: 2D 우선 확정 여부, 신규 갈등의 사실 증거 계약 및 온라인 착수 순서 검토. 이 파일은 전달용 회신이며 다른 채팅으로 자동 발송하지 않았습니다.
