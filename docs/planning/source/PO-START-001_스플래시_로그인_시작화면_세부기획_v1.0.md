# PO-START-001 — 스플래시·로그인·월드 시작 화면

- 김PO → 김도현·김디자인 / 작성일: 2026-10-13 / v1.0
- 기준: 사용자 시작 화면 추가 요청, PO-AUTH-001, PO-DEC-006, DES-12.
- 상태: 제품/화면 제작 명세. 실제 이미지·코드·사용성 검증 완료 아님.

## 1. 시작 경험의 목적

‘내가 만든 폰이 함께 살아가는 공간’이라는 분위기를 먼저 보여 주고, 새 사용자와 돌아온 사용자 모두 데이터를 잃지 않고 시작하게 한다. 로그인은 계정 저장과 복구를 위한 선택이며 게스트 플레이를 숨기지 않는다. 인증 상태와 현재 월드의 실제 저장 위치를 분리한다.

흐름: 짧은 준비 화면 → 시작 화면 → 로그인 또는 이 기기 플레이 → 필요한 월드 선택/가져오기 → 일시정지 월드 진입 → 사용자가 생활 재개.

## 2. 스플래시 준비 화면

- 《동그란 사이》 제목과 간단한 원형 모티프를 중심에 둔다. 영문/일문 제목 후보를 최종 로고로 확정하지 않는다.
- ‘폰들의 하루를 준비하고 있어요.’ 같은 실제 준비 상태를 표시한다. 진행률을 계산할 수 없으면 가짜 퍼센트를 보여 주지 않는다.
- 앱 자산·로컬 저장 형식·외부 인증 callback 또는 비밀번호 재설정 callback 여부를 확인한다. 인증 관련 callback 처리를 일반 시작 화면보다 먼저 한다.
- 정해진 3초 광고처럼 강제로 기다리지 않는다. 준비가 끝나면 바로 전환한다. 배경 모션은 장식이며 시뮬레이션 tick/욕구/관계/보상을 진행하지 않는다.
- 재접속 세션 확인이 지연돼도 끝없이 화면을 가두지 않는다. 확인 중 안내와 ‘이 기기에서 계속하기’를 제공한다. 늦은 인증 응답이 이미 선택한 월드를 자동 교체하지 않는다.
- 저장 손상/새 버전 미지원은 원본 보존·복구/내보내기 안내로 전환한다. 실패했다고 자동 새 월드를 만들지 않는다.

## 3. 최초 시작 화면 배치

| 영역 | 구성 |
|---|---|
| 배경 | 포근한 2D 공간과 원형 폰의 작은 생활 장면. 실제 내 월드로 오인시키지 않는 장식 시안 |
| 제목 | 동그란 사이 |
| 한 문장 | ‘작은 폰들이 함께 살아가는 나만의 공간’ — 초기 카피, 실제 화면 검수 후 조정 가능 |
| 첫 로그인 선택 | Google로 계속하기 |
| 두 번째 선택 | 이메일로 계속하기 |
| 별도 게스트 선택 | 이 기기에서 시작하기 |
| 보조 안내 | ‘로그인하면 월드를 계정에 저장하고 다른 기기에서 불러올 수 있어요.’ 구현된 범위에서만 사용 |
| 하단 | 언어/소리 설정, 실제 제공되는 이용·개인정보 안내 링크 |

소리 자동 재생을 강제하지 않고 장식 모션 줄이기를 지원한다. 그림에 입력칸·버튼·문자를 굽지 않는다. Google 버튼은 공식 브랜드 규격으로 구현/검수한다. 폰은 예시 캐릭터이며 플레이어 외형을 덮어쓰지 않는다.

## 4. 돌아온 사용자 화면

### 로컬 월드가 있는 게스트

첫 버튼은 ‘이 기기의 월드 이어하기’. 월드 제목·폰 수·마지막 확정 저장·이 기기 저장임을 표시한다. Google/이메일 로그인은 아래의 계정 저장 선택으로 유지한다. ‘새 월드 만들기’는 보조 선택이며 기존 월드 보존/별도 생성 확인 없이 초기화하지 않는다.

### 유효한 로그인 세션

‘로그인 상태: 현재 계정’과 ‘월드 저장 위치/현재 작업 사본’ 두 줄을 보여 준다. 이메일은 필요할 때 일부 가림, 실명/프로필 사진을 공개 폰 정보로 자동 반영하지 않는다.

계정 월드 목록이 준비되면 제목·폰 수·마지막 서버 확정 저장·선택 상태를 표시한다. 계정 월드와 로컬 월드가 모두 있으면 ‘계정 월드 불러오기’/‘이 기기의 월드 이어하기’/‘현재 로컬 월드를 계정에 별도 저장’을 구분한다. 다른 월드를 조용히 덮어쓰지 않는다.

선택한 월드를 불러온 뒤 paused 상태로 진입한다. 로그인/조회만으로 계정 저장 성공을 표시하지 않는다. 로컬 월드를 계속 사용하면 계정 세션이 있어도 ‘현재 월드: 이 기기’라고 표시한다.

### 만료/계정 전환

계정 인증 전 이전 계정의 월드 이름·폰 그림·이메일을 새 게스트에게 노출하지 않는다. 세션 만료는 재로그인/로컬 보호를 안내한다. 계정 전환 시 이전 계정 캐시 분리·월드 정지·초안 보존을 PO-AUTH-001대로 적용한다.

## 5. 이메일 화면과 외부 인증

이메일 진입은 로그인 탭을 기본으로 이메일/비밀번호·보기 토글·로그인 버튼·비밀번호 재설정·회원가입·뒤로가기를 제공한다. 가입은 이메일/비밀번호/확인 및 실제 제공되는 이용 안내를 구성한다. 필수 동의를 불필요하게 늘리거나 마케팅 동의를 기본 선택하지 않는다.

확인 대기에는 이메일 확인 안내·재발송 제한·주소 수정/돌아가기를 제공한다. 일반 로그인/재설정 오류는 계정 존재를 구체적으로 공개하지 않는 인증 응답 계약과 일치시킨다. 비밀번호 재설정 callback은 로그인 탭이 아니라 새 비밀번호 설정 화면으로 직접 연결한다.

Google callback은 인증 완료/취소/실패를 분리한다. 취소는 정상 선택이며 월드/관계 벌점 없음. 같은 이메일의 공급자 자동 연결은 PO-DEC-006대로 안내하며 게임 자체 계정 병합은 하지 않는다. 인증 UI/Google/메일 설정이 미완료면 ‘준비 중’ 또는 시험 환경 표시를 사용하고 누르면 가짜 성공하지 않는다.

## 6. 상태별 화면 계약

- 준비 중: 기다리는 이유와 재시도/게스트 대안. 진행률 조작 없음.
- 로그인 중: 중복 요청 방지, 이전 로컬 상태 유지, 취소 가능한 범위 안내.
- 로그인 성공: 계정 표시만 갱신. ‘월드가 계정에 저장됐어요’와 혼용 없음.
- 계정 저장 중: 로컬 사본 보존, 서버 확정 전 성공 연출 없음.
- 저장 충돌/실패: 지속 안내·최신 상태 확인·명시 선택·멱등 재시도. 원본 덮어쓰기 없음.
- 오프라인: 이 기기 플레이 가능, 서버 저장·복구는 연결 후. 없는 계정 월드를 조회된 것처럼 표시하지 않음.
- 빈 계정/빈 로컬: 폰 생성부터 안내. 로그인 실패를 빈 계정이라고 오인하지 않음.

DES-12 두 줄 계약은 계정 상세에도 유지한다. 스냅샷 사본 생성만 완료한 경우에는 ‘계정 사본 생성됨’으로 표시하고 이후 자동 동기화를 암시하지 않는다.

## 7. 디자인·개발 납품

김디자인은 준비/첫 시작/로컬 이어하기/로그인된 시작/이메일 로그인·가입·확인·재설정/실패·오프라인/월드 충돌의 화면 상태표와 PC·폰 세로·가로 와이어프레임을 우선 제출한다. 최신 DES12 상태 문구를 재사용한다. 제목·배경 원본·버튼을 분리하고 새 배경 이미지는 실제 레이아웃 확정 뒤 필요할 때 제작한다.

김도현은 시작 라우팅·callback 우선 처리·세션/저장 상태·게스트 분리·초안 보존·입력/로딩/중복 계약과 실제 렌더 크기·안전영역·지원 환경을 제안한다. 김PO가 자산 크기/파일명/확장자/상태 규격을 취합해 디자인에 전달한다. 로그인 정책/브랜드 문구와 기술 설정은 PO-AUTH001/SB0003의 최신 결정과 대조한다.

## 8. START 수용 기준

START01 최초 게스트 시작, START02 기존 로컬 이어하기/새 월드 선택과 원본 보존, START03 유효 세션/계정 목록과 저장 위치 분리, START04 Google 성공/취소/실패 callback, START05 이메일 가입/확인·로그인·재설정 callback, START06 인증 지연/오프라인에서 게스트 대안, START07 로컬·계정 양쪽 월드와 충돌/명시 선택, START08 계정 전환·만료의 비공개 캐시 격리, START09 PC/폰 세로/가로·확대·키보드 포커스·모션/소리, START10 중복 callback/재조회/복구에서 새 월드/관계/발화/보상 재실행0.

실행 증거는 AUTH01~12와 연결하되 번호를 합치지 않는다. 단위 mock·실제 provider·UI 관찰을 구분한다. 이미지 시안은 실제 로그인/저장 통과가 아니다.
