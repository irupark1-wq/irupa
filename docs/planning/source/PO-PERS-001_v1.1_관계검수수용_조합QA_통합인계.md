- 김PO → 김도현 / 참조 정연우·김시스템·김플레이·김디자인
- 작성일: 2026-10-13
- 근거: 사용자 메시지로 전달된 정연우 첫4종 관계 검수 v1.0, PO-PERS-001 v1.0, DES-12 v1.0.
- 상태: 관계 의미 기준 수용 및 추가 검증 명세. 카드 가중치·실제 구현·시험 통과·자동 발송 완료 아님.
- 적용: PO-PERS-001 v1.0의 결정은 유지하며 본 개정으로 조합/콘텐츠/검수 기준을 보완한다.

## 1. 수용 결정

다정함은 순종, 욱함은 악의, 고집은 사실 부정, 독립성은 낮은 애정이라는 규칙을 만들지 않는다. 성격은 행동 이유 중 하나이며 관계 변화의 독립 source가 아니다. 기존3축·인지·기억·상대 거절·소유권·실제 완료 증거가 카드보다 우선한다.

정연우는 새 delta/severity/관계축을 제안하지 않았으므로 이번 회신을 수치 변경 승인으로 해석하지 않는다. 0~3장·권장2장·첫4종·미지원카드 선택불가 및 과거 snapshot 보존을 유지한다. 로그인/시작화면·저장·두방 기존 우선순위도 유지한다.

## 2. 6개 두 장 조합의 관찰 기준

| 조합 | 기대 가능한 행동 | 금지되는 고정 결과 |
|---|---|---|
| 다정한+욱하는 | 도움 제안과 빠른 사실 확인 | 도움 뒤 반드시 싸움 |
| 다정한+고집 센 | 상대를 챙기면서 자신의 기준 설명 | 친절하므로 무조건 양보 |
| 다정한+독립적인 | 혼자 시간을 지키면서 한정 도움 | 혼자 있음=냉담/신뢰 하락 |
| 욱하는+고집 센 | 빠른 문제 제기와 근거 요구·수용 가능 | 두 카드만으로 갈등250 |
| 욱하는+독립적인 | 불편 표현 뒤 혼자 휴식·대체 활동 | 불편 표현=관계 단절 |
| 고집 센+독립적인 | 자기 방식과 동의한 공동목표 협력 | 모든 공동작업 거절 |

모든 카드의 영향은 유효 후보 안에서 비교한다. 같은 조합이라도 피로·관계·현재 목표·인지 기억이 다르면 반응이 달라질 수 있다. 실제 특정 행동을 반드시 고르도록 seed를 보상 규칙처럼 사용하지 않는다.

## 3. 조합 시험 범위

첫4종의 0~3장 구성은 총15세트(미선택1+단독4+두장6+세장4)다. 이는 기존 내부3축의27조합 및 기존공방27경로와 별도 집합이다. 15세트의 입력 유효성·선택순서·중복·상한·저장/복구를 확인하고, 생활 의미 비교는 대표상황으로 수행한다. 모든 내부기질/관계/공간과의 전수 곱집합을 즉시 완료 요구로 추가하지 않는다.

세 장 조합4개도 지원한다: 다정한/욱하는/고집 센, 다정한/욱하는/독립적인, 다정한/고집 센/독립적인, 욱하는/고집 센/독립적인. 카드별 가중치를 무제한 합산해 3장 선택이 항상 최적이 되지 않게 한다. 같은 카드 세트는 선택 순서와 무관한 결과·같은 규칙 버전을 사용한다.

김시스템은 후보별 합성 방식·최대 영향·동률·기존3축과 겹침·상대 독립 반응을 명시한다. 공정성 high→항상포함 등 앞서 거절한 stance 고정매핑을 새 카드로 우회하지 않는다. 김도현은 구현 영향/비용을 제시한다. 아직 해당 시스템안을 받지 않았으므로 임의 계수를 김PO가 확정하지 않는다.

## 4. 생활 장면의 증거 경계

정연우 장면 A의 ‘내 이름이 왜 빠졌는지 확인’은 실제 기여·게시·인지가 있을 때만 발화한다. 설명 수용으로 갈등 없이 종료할 수 있다. 카드 때문에 EVT10/갈등250을 생성하지 않는다.

장면 B의 ‘마지막 고장 난 부분을 고쳤다’는 **서사 예시**다. 실제 작업 모델에 고장/수리 기여가 없다면 폰이 이를 사실처럼 말하거나 과거 기억을 만들지 않는다. 현재 저장된 기여/작업 근거로 문구를 바꾸거나 별도 콘텐츠 후보로 제안한다. 고집 센 폰도 검증된 새 근거를 읽고 입장을 바꿀 수 있어야 한다.

장면 C의 ‘재료 위치만 알려준다’ 역시 실제 정보 참조·위치 인지·허용된 전달 행동이 있어야 완료 사건으로 쓴다. 해당 기능이 없으면 기존 지원 도움 범위로 작은 대안을 설계한다. 친절한 응답만으로 acceptedCommitment·지속 역할·의무를 추가하지 않는다.

실제 데이터가 없는 대사/행동은 design_only 후보로 남긴다. 예문을 그대로 코드에 넣는 작업과 생활 콘텐츠 구현은 구분한다.

## 5. PERS-C01~12 보완

기존 ID와 기대 의미를 유지한다. 특히 C01~04는 후보/우선순위/자발적 반응과 실제 완료를 따로 검증한다. 단순 문구 교체만으로 pass 금지. C05 권한/피로/거절 우선, C07 같은카드·다른관계/기억, C08 당시 snapshot/replay, C12 성격만으로 부정 source/갈등 생성0을 필수로 확인한다.

C06에 15세트 및 순서/중복/3장 영향상한 검사를 연결한다. 임의 신규 QA번호로 기존 합격처럼 바꾸지 않는다. 고집의 입장수정·독립적 협력은 유효한 후보 존재 및 독립 수락을 평가하고 특정 tick 필연 행동으로 단정하지 않는다.

## 6. DES-12 연계

이번 첨부 DES-12는 이전 수신한 로그인/저장 UI 문서다. 신규 카드 UI 납품으로 기록하지 않는다. 인증 상태와 현재 월드 저장 위치의 두 줄, 사본/활성 월드·실패/만료/로그아웃 구분은 PO-START-001/PO-AUTH-001에 연결한다.

카드 UI는 별도 PERS 디자인 요청으로 신규/기존폰·미선택/선택·지원여부·설명/예시·취소/저장/실패를 제안한다. 새 로그인 화면이 생긴다고 성격 선택을 로그인 버튼에 묶거나 게스트의 카드 기능을 막지 않는다.
