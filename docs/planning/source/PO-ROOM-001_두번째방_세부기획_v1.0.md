## 2. 월드·이동 상태

폰은항상한room에만존재한다. 같은pawn ID·외형·성격·관계·기억·약속을유지한다. 방전환은카메라/열람전환이며폰이자동따라오지않는다. 초기기존폰은현재방에유지하고새방은빈방으로추가한다. 폰복제·새초기관계추첨없음.

편집/폰이동은월드주인만, 미리보기중시뮬레이션정지. 대상방을보여주고 도착가능빈칸을선택/제안하며 안전칸이없으면이동거절. 가구/장식/장애물/다른폰칸이나고립칸에놓지않는다. 방으로옮기기는플레이어배치행동이며폰경로찾기/자율순간이동으로표시하지않는다.

확정은단일저장으로source방점유/활동과destination위치를함께갱신한다. 이동중가벼운활동은중립취소·자리해제하며 허위완료/관계벌점없음. acceptedCommitment/기한/책임은방이동때문에자동삭제하지않는다. 방이동상태·취소사유를보존하고 향후위임/약속활성화전이동영향을검수한다. 실패/버전충돌은원래방·좌표·점유유지,초안재시도/취소가능. 확정/편집끝에도자동재개없음.

로컬방문대역은이번수동방이동대상에서제외한다. 기존방문방에머무르며방전환으로숨겨질뿐소유권/참여허용을바꾸지않는다. 실제친구폰방이동/입퇴장권한은B1에서별도정의한다.

## 3. 두 방의 생활과 사건

한world clock/seed/저장version에서각방의활동·점유·경로를진행한다. 다른방폰끼리원격대화/도움/목격을발생시키지않는다. 동일방조건과유효거리/경로가있어야상호작용한다. 도움당시room/활동scope는증거에보존한다. 방이동이원과거scope를바꾸거나갈등을지우지않는다.

관계/Day/반복자격은월드공유,가구/장애물/배치는room별. 방이름/가구ID를효과상한scope로써서우회하지않는다. 전체일지는공개room표시와방필터를지원할수있으나열람권한우회없음. 다른방발화는현재화면에떠다니지않고공개일지에서확인한다. 방전환/reload로과거대사재연출없음.

## 4. 배경 장식과 사용가능 공간

아늑한방배경의침대/책장은장식이며해당영역을정의된grid마스크로막는다. 디자이너/개발자는실제배경원본·표시앵커·가구범위와논리칸을대조한다. 경계/상호작용구분을읽을수있게한다. 포스터나벽선반처럼바닥점유가없는벽장식은불필요하게바닥칸을막지않는다.

정확한장식칸좌표는원본을현재렌더에맞춰개발자가초안을제출하고김디자인검수후확정한다. 원본이불일치하면사용가능영역을작게숨기지말고분리자산/배경수정안을제안한다. 초기방layout은3활동지점과폰진입가능빈칸이연결돼야한다.

장식차단칸은사용자장애물30칸집계와구분한다. 고정장식은사용자장애물지우기로제거되지않는다. 방마다열린장소도달·고립방지·현재폰칸·가구충돌을PO14와같이판정한다.

## 5. 화면·문구

방선택은현재방·해당방폰수·빈방을읽게한다. ‘이방보기’와‘폰옮기기’는분리한다. 빈방에는‘아직이방에폰이없어요. 폰을옮겨함께지내게할수있어요.’ 안내. 안전칸없음은‘폰이설자리가없어요. 빈칸과통로를만들어주세요.’를사용한다. 폰의생활을멈추는정지표시와카메라방전환을혼동하지않는다.

기존얼굴/가구/관계창을재사용한다. 방간전환·폰이동·장식고정영역·실패/빈방의상태만추가한다. 실제자산규격은김도현이김PO에게요청하고김디자인에게인계한다.
