# PO-PERS-002 — 성격·관계 자율 생활 다음 버전 세부기획

- 김PO → 김도현 / 관계 검수: 정연우 / 규칙: 김시스템 / 콘텐츠: 김플레이 / UI: 김디자인
- 작성일: 2026-10-14 / 버전: 1.0
- 상위 지시: PO-HAND-015. 기존 PO-PERS-001 v1.1의 0~3장·권장2장·첫4종·PERS-C01~12 유지.
- 본 문서는 행동 의미와 제작 계약을 확정한다. 미수신 시스템 가중치를 승인한 것으로 해석하지 않는다.

## 1. 이번 플레이 경험

플레이어는 폰의 성격을 고르고 공간을 마련한 뒤 생활을 관찰한다. 폰을 눌러 대화 선택지를 골라야 관계가 진행되는 구조로 만들지 않는다. 같은 공간에서도 어떤 폰은 도움을 제안하고, 어떤 폰은 먼저 쉬며, 어떤 폰은 기록을 확인하거나 자신의 기준을 설명한다. 서로 다르게 반응하되 모두 협력·거절·설명 수용이 가능하다.

모든 행동은 상대를 필요로 하지 않아야 한다. 대화가 거절되거나 효과 상한에 걸려도 혼자 쉬기·작업 등 기존 유효 생활을 계속한다. 거절이 반복되는 정체 상태를 방지하되 거절권을 우회해 접촉을 강제하지 않는다.

## 2. 카드별 구현 의미

| 카드 | 우선 주목할 유효 후보 | 반드시 남길 가능성 | 금지 |
|---|---|---|---|
| 다정한 | 안부·도움 제안·상대 불편 확인 | 피곤하면 거절·자기 활동·한정 도움 | 모든 요청 수락·무한 책임 |
| 욱하는 | 알고 있는 불일치에 빠른 확인 질문·불편 표현 | 이유 듣기·진정·설명 수용 | 정보 없이 항의·악의 단정·자동 갈등 |
| 고집 센 | 기준 설명·재확인·근거 검토 | 검증된 새 근거에 입장 수정 | 사실 조작·영구 거부 |
| 독립적인 | 혼자 활동·휴식·자기 목표 | 필요하고 동의한 협력·도움·대화 | 낮은 애정 강제·모든 공동작업 거절 |

독립적인 폰의 혼자 쉬기는 관계 손상 사건이 아니다. 다정한 폰의 도움 제안은 완료된 도움과 구별한다. 욱하는 폰의 질문은 갈등과 구별한다. 고집 센 폰이 의견을 유지한다는 사실만으로 부정 감정 기여를 만들지 않는다.

## 3. 행동 처리 계약

처리는 사실·인지·권한·피로·위치·현재 활동 등 후보 적격성 확인 → 기존 기질/관계/목표/기억과 카드 선호 반영 → 후보 선택 → 상대 독립 수락/거절 → 실제 실행 → 승인된 사건 기록의 순서로 구분한다. 구현 내부 함수 구성은 개발자 판단에 맡기되 이 경계를 증거로 추적할 수 있어야 한다.

카드는 부적격 행동을 살리거나 상대의 거절을 제거하지 않는다. 내부3축을 재추첨하지 않는다. 카드 효과는 후보 선호 계층에 적용하고 기존 관계 계산을 직접 수정하지 않는다. 같은 세트는 선택 순서와 무관하다. 중복 카드 불가, 최대3장, 15세트 유효성 유지. 무제한 합산 대신 김시스템이 합성·상한을 명세한다.

현재 후보가 없는 ‘불편 표현/근거 검토/설명 수용’은 지원된 대화에 의미 있는 실행 조건을 연결하거나 최소 행동 정의를 먼저 제출한다. 단순 문자열 변경으로 대체하지 않는다. 미구현 수리·재료 전달·감정 진정 미니게임을 예문만 보고 추가하지 않는다.

## 4. 대표 검수 장면

| 장면 | 입력 조건 | 기대 결과 | 나오면 안 되는 결과 |
|---|---|---|---|
| 배려와 거절 | 도움 대상 존재, 다정한 폰의 충분한 여력/높은 피로를 나눠 비교 | 여력에 따라 도움 후보와 자기 휴식의 우선순위가 달라짐; 상대 거절 존중 | 피로 무시·거절 뒤 강제 실행 |
| 빠른 확인 | 욱하는 폰이 실제 기여 누락 기록을 읽은 경우/모르는 경우 비교 | 알고 있을 때 확인 후보 증가; 모를 때 그 사건 관련 항의 없음 | 카드만으로 누락·고의·갈등250 생성 |
| 근거에 따른 수정 | 고집 센 폰의 기존 해석과 실제 새 증거 존재 | 기준 설명과 검토가 가능; 새 근거 수용 경로 존재 | 성격 때문에 검증된 사실 무효화 |
| 독립적인 협력 | 혼자 쉬고 싶은 상황/동의한 공동 목표와 충분한 여력 비교 | 혼자 활동 선호와 협력 가능성이 공존 | 모든 공동작업 거절·애정 자동 하락 |
| 싫지만 협력 | 낮은 애정, 협력 적격성을 갖춘 존중·목표·동의 | 협력 후보가 가능하되 친밀 표현은 강제되지 않음 | 협력=사랑 증가·일괄 차단 |
| 회복 후 거리 | 정정/합의가 확인된 사건과 낮은 친밀·혼자 시간 선호 | 해당 쟁점 정리와 개인적 거리 유지가 공존 | 화해=친밀 최대·기억 삭제 |

관계 초기 수치·내부3축·배치·증거 source·seed는 담당자가 기존 시험 fixture에 맞춰 명시한다. 정의되지 않은 수치를 김PO가 임의로 확정하지 않는다. 후보 경향은 동일 조건의 비교로 확인하고, 실제 장면은 재현 가능한 입력으로 제출한다. 특정 행동을 모든 실행에서 강제하지 않는다.

두 장 조합6종은 PO-PERS-001 v1.1의 의미를 유지한다. 세 장4종과 미선택도 저장/순서/상한을 검증한다. 카드 없는 폰은 기존 생활을 유지한다.

## 5. 관계 서사와 불화

사실 인지 → 서운함 해석 → 확인할 쟁점 → 활성 갈등을 구별한다. 설명을 듣고 갈등 없이 끝나는 경로와, 실제 원인·대립·피해가 있어 승인된 분쟁 조건을 충족하는 경로를 모두 제공한다.

사용자가 원하는 불화는 유효한 상황과 다른 해석에서 발생하게 한다. 무작위 강제 싸움, 카드 선택만으로 감정 감점, 갈등 발생률 목표를 맞추기 위한 사건 조작은 하지 않는다. 승인된 국소 분쟁250의 범위를 확장하지 않는다. 실제 조건이 부족하면 쟁점 상태로 남고, 빈도를 높이기 위한 새 원인 콘텐츠는 별도 CR로 검토한다.

정정·인지·정정자 확인·합의·감정 회복은 독립 처리한다. 설명이나 복구로 쟁점을 정리해도 애정·신뢰가 자동 최대가 되지 않는다. 반복 상한·Day·중립 기록·기억 재해석은 기존 계약을 유지한다.

## 6. 말풍선과 관계창의 최소 보완

폰 위에는 실제 실행 중인 발화만 표시한다. 예: ‘지금은 조금 쉬고 싶어’, ‘그 기록은 다시 확인해 줄래?’. 사실을 요구하는 문장은 그 폰이 해당 사실을 알고 있을 때만 사용한다. 예문은 데이터와 연결된 뒤 지원 콘텐츠가 된다.

대사에는 발화 주체·상대·행동 단계·필요 인지·공개 범위·종료 조건을 연결한다. 동시 말풍선 겹침과 빠른 연속 발화를 제한하고, 정지 중 남은 표시 시간을 유지한다. 다른 폰의 비공개 기억이나 내부 성격 가중치를 발화로 누출하지 않는다.

관계창은 방향과 기존8축을 유지하고 ‘최근 실제 사건’과 ‘이 폰의 해석’을 구별한다. 해석이 미확인임을 읽을 수 있게 한다. UI 때문에 관계 총점이나 선악 등급을 만들지 않는다. 개발 추적 자료는 일반 관계창과 분리한다.

## 7. 선택·저장·검증

지원된4종만 선택 가능하다. 기존 폰에는 자동 부여하지 않는다. 변경은 앞으로의 행동에만 적용한다. card_ids·적용 시작 순번·카드/규칙 버전·당시 snapshot을 저장하고, 과거 replay에 현재 카드를 소급하지 않는다. 저장 실패 시 전체 이전 상태로 복구한다. 계정 저장·두 방·이전 형식 호환을 검증한다.

PERS-C01~12의 기존 ID를 사용한다. 각 증거에 초기 상태, 카드/기질, 관계/기억, 위치, seed/규칙, 후보 적격성·점수 차이, 선택·상대 반응·완료 사건을 남긴다. 김PO에는 읽기 쉬운 장면 설명과 짧은 영상/연속 화면을 함께 제출한다. 내부 추적을 공개 DTO에 추가하지 않는다.

통과 기준은 실제 행동 차이, 상황에 따른 다양성, 거절·인지 경계 보존, 저장 불변성이다. 자동시험 통과와 플레이 장면 검수를 모두 보고한다. 배경 양산 완료·새 카드 추가·시험 개수 증가로 이 기준을 대신하지 않는다.
