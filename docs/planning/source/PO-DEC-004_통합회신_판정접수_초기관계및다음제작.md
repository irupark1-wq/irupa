## 2. DEV-23 초기 관계 제안에 대한 결정

**신규 월드에서 폰 쌍별 시작 관계를 소폭 다르게 만드는 방향을 조건부 채택한다.** DEV-23 4절 원문은 미수령이므로 아래는 김PO의 제한된 시험안이며 개발자 제안과 동일하다고 주장하지 않는다.

- 새 관계의 애정·신뢰·존중만 각 기준값에서 -20~+20 정수의 재현 가능한 편차를 허용한다. 이 폭은 A2 체험 시험값이다.
- 방향별 A→B/B→A는 독립 가능하며 월드 seed와 안정적 폰 ID·초기화 규칙 버전으로 한 번 생성·저장한다. 조회·복구·성격/외형 수정·Day 변경 시 재추첨하지 않는다.
- 의존1·권력500(no_active_basis)·호혜성500·의무1·갈등1은 기존 기본값을 유지한다. 근거 없는 갈등/책임/권력 역할을 랜덤으로 만들지 않는다.
- 초기 편차는 설정된 시작 평가이며 실제 과거 사건·거짓 기억·긍정 source를 생성하지 않는다. 두 source/세 긍정 태그 조건도 충족하지 않는다.
- 기존 폰의 관계·기억은 변경하지 않는다. 시험 fixture는 명시적 초기값을 우선하여 고정 기대값을 깨지 않는다. 신규/기존 저장과 실제 온라인 적용을 구분한다.
- 이 작은 편차를 다양한 불화 발생의 대체 구현으로 쓰지 않는다. PO-REQ-001의 행동/기억/갈등 생성 다양화는 계속 필요하다.

김도현은 DEV-23 원문과 이 시험안의 차이·재현성·새 저장 버전 영향을 회신한다. 시작 시점·분포·기술 구현을 조정할 필요가 있으면 이유와 대안을 제시한다.

## 3. REQ-04 두 번째 방

사용자 요청에 따라 두 번째 방을 다음 세부기획 대상으로 접수한다. REQ-04 1절의 7개 항목 및 기본값은 미수령이다. 보지 못한 기본값을 ‘유지’로 확정하거나 방 크기/가구 수를 임의로 대신 정하지 않는다.

김도현은 REQ-04의 7항목 표와 현재 방 간 이동/저장 구현 상태를 보내 준다. 김PO는 해당 표에 유지/수정과 사용자 경험·수용 기준을 붙여 별도 방 세부기획으로 회신한다. A1의 1개 방 기준은 기존 검증에 유지하고 두 번째 방은 범위 확장으로 버전을 분리한다. 빈 문서를 완료 세부기획으로 납품하지 않는다.

## 4. 첨부 회신 수용

### 김디자인 DES-07

접근/거절/완료/중립/미인지/저장·정정 상태 분리, 일지 묶음, 사실/해석/사유/해결 구획을 제작 기준으로 수용한다. 모두 실행 not_run이며 A1/A2 통과 근거는 아니다. PO-14를 재전달한다. decline 이미지의 의미를 기술 단절·길막에 확대하지 않는다. 말풍선8종 원본은 이번 자료에 없고 개별 매핑이 미검증이므로 실제 대화 텍스트 요구 PO-REQ-001과 별도 확인한다.

중립 묶음은 공개 물리 완료 기준, Day/상대/활동/정정 경계에서 끊고 펼치기를 제공한다. 숨은 source의 존재를 ‘미확인 사건’ 카드로 누출하지 않는다. 공개 knowledge revision 등 ID는 개발자가 권한·노출 영향을 검토해 안전한 UI 갱신 참조를 제안한다. 비공개 revision을 그대로 전달하라는 요청이 아니다.

### 정연우 v1.1

STORY-C 여섯 증거와 정정/복구 분리, AUTO11/16/22 후보/성공 분기 분리, 가벼운 비민감 작업 메모의 상태 모델을 관계 서사 설계로 수용한다. 시험 수치는 해당 definition 버전과 일치하는지 개발 검수 후 사용한다. 정확한 conflict 종료·파생갈등 재계산을 숫자 -200만으로 대신하지 않는다.

가벼운 위임은 같은 소유자·단일 공개 작업 메모의 제안/거절/수락/전달/확인 사실 모델까지 채택한다. 실제 책임 범위·기한·취소·의무 원천·EVT06/07 기여 매핑은 정의 확정 후 활성화한다. 미정 상태에서 작은 위임에 큰 약속 보상을 넣지 않는다. 방문 대역 책임 scope를 확장하지 않는다.

REL v1.1의 시계/정정 보완과 사례 구분을 문서 수용한다. 비대칭 기여발견 definition의 blocked는 유지한다. 수락을 고정한 테스트는 자율 생활의 실제 발생 증거와 구분한다.

### 김시스템 v1.2

SYS-PROP-001 전체개정 및 26개 설계 fixture, 과거 MD/JSON ID 대응표를 수신했다. 문서상 번호 불일치 보완을 수용하되 게임 실행 pass로 올리지 않는다. 신규 REL v1.1도 같은 패키지로 전달하므로 ‘정연우 수정본 미수령’은 이 인계 시점부터 갱신한다. 구체 definition/마이그레이션/실제 출력은 여전히 검수 사항이다.

김플레이 원본 카드가 이번 첨부에도 없으므로 신규 콘텐츠2개 선정은 계속 대기한다. 외주 문서가 반복 기반만 늘리고 콘텐츠 없이 끝나지 않도록 OUT-PLAY-001/002 결과를 우선 수신한다.
