## 반복 효과의 세부 조건

접근 가능 여부·상대 수락·반복 감정 효과는 별도다. 상한에 도달해도 중립 대화·다른 생활은 가능하다. 새로 완료된 인사/대화는 효과 0 기록을 남길 수 있지만 태그의 긍정 사건 횟수에는 넣지 않는다. 같은 action/source 재전송은 새 기록이 아니다. 갈등·정정·복구는 인사 상한에서 제외하되 독립 근거와 멱등성은 유지한다.

Day별 초기화는 반복 집계만 초기화하며 관계·기억·태그·약속·갈등을 초기화하지 않는다. 현 60tick 접근 제한과 종류별 3회 효과 상한은 출시 밸런스가 아닌 시험 규칙이다. Day 경계 사건은 완료 확정 tick의 Day에 집계하는 안을 기본으로 제안하되 김도현이 현재 commit 구조와 대조해 회신한다.

## 계정 연결 단계의 납품

B-ACCOUNT에는 로컬 시작과 온라인 식별의 연결, 폰 소유권 검증, 중복 연결/충돌, 복구·삭제·연결 실패 시 로컬 자료 보호를 포함한다. 익명 계정과 정식 계정의 방식·기술은 개발자가 제안하고 제품 정책은 김PO가 판정한다. 기존 공유 서비스 연결 사실과 게임 사용자 계정 연결 완료를 혼동하지 않는다. 운영 Auth/DB·배포 변경은 구체안 제출 후 별도 결정한다.

단계 순서는 A1 → A2 → A3 → B-ACCOUNT → 실제 친구 공존 B1이며, 온라인 설계 B0는 A2/A3와 병행할 수 있다. 기존 B0/B1 전체계획을 이 순서로 보완한다.
