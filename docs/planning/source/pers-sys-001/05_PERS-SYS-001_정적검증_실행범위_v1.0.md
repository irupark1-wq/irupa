# PERS-SYS-001 정적 검증 및 실제 실행 범위 v1.0

- 작성: 김시스템 / 2026-10-14
- 실제 실행: **이 패키지의 JSON fixture 생성 Python 스크립트와 정적 산술 검증만** 수행.
- 실제 미수행: 프로젝트 빌드·플레이/생활 tick 시뮬레이션·연속 화면/영상·실기기·계정 저장/두방 회귀·서버·DB 테스트.

## 정적 검사 항목

1. 4종 카드의 유효 0~3장 조합 수 = `1+4+6+4=15`.
2. 시험 ID `PERS-C01`~`PERS-C12` = 12개, 대표 장면 6개.
3. 모든 후보별 카드 합성값이 [-14,+14] 범위에 있음.
4. 모든 카드 세트에 대해 입력 카드 ID의 모든 순열이 동일한 합성값이 됨.
5. 0장 카드 모든 보정이 0이고, `warm+independent/meet=-5`, `warm+independent/assist_joint_goal=13`, `warm+quick+firm/credit_ask_known=14` 계산 일치.
6. JSON 모든 시험 항목은 `status:not_run`, 상위 객체는 `production_import_allowed:false`.
7. JSON은 Python 생성 이후 별도 재파싱과 파일/ID 검사를 거친다. (패키지 최종 생성 명령에서 실행)

## 제한

이 검증은 **기획용 수식의 산술 정합성**만 확인한다. 각 행동의 실제 eligibility, `base_score` 계층과 단위, 카드 수에 따른 분포/편향, seed 결정론, 정정·인지/기억·미인지 replay, DTO 비공개, 실제 관계 사건은 김도현 개발자의 최신 코드 시험 결과가 필요하다. `PERS-C01~12`는 이 파일에서 **모두 미실행**.

이전 로컬 ZIP 소스와 DEV-25 문서의 설명은 참고용일 뿐 최신 통합 실행 결과가 아니다. 김PO의 새 정책과 원문을 변경하지 않았다.
