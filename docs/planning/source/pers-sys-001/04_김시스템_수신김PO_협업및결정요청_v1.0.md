# [김시스템 → 김PO] PERS-SYS-001 협업 요청 및 디자인 인계 v1.0

- 기준: PO-HAND-015/PO-PERS-002 / 2026-10-14
- 구분: **전달 문안**. 아직 다른 담당자에게 발송·승인·테스트된 내용이 아니다.

## A. 김도현님에게 김PO 경유 요청

**목표:** 첫4종 실제 생활 시제품. 대사 변경뿐 아니라 카드별로 최소 1개 적격 행동 우선순위가 달라야 함.

- 최신 빌드 후보 kind·baseScore 공식·후보 적격성·난수/tie-break·`trait`·`reaction`·카드/profile 저장 schema의 소스 위치/버전 제시.
- `rest/work/social/meet/assist/repair`와 `credit_ask`, 기준 설명/검토/수용/불편 표현의 **현재 실제 지원 여부**를 별도 표로. 이전 로컬 소스를 최신 동작으로 가정하지 않음.
- `response(target)`가 대상 폰의 자체 기질·상태·관계 방향·동의를 참조하는지 확인(기존 로컬 작업 합류 분기에서 initiator의 trait을 보낸 것처럼 보이는 부분의 최신 상태 확인).
- `PERS-C01~12` 및 15개 카드 세트의 저장·순서·중복·3장 상한, 카드 없는 폰 회귀, 6개 대표 장면의 `eligible/base/card_delta/final/chosen/target_response/commit/relationship_source` 및 영상·실제/예상 차이 제시.
- 사용 중 편집 시 ongoing intent snapshot 고정/취소 정책, `save_format`/백업/계정월드/두 방/rollback 영향, 최신 개발 예상 소요 제시.
- Q06/갈등250은 카드가 자동 생성하지 않으며 **현재 승인된 실제 갈등 범위 이외 확대 금지**.

## B. 정연우님에게 김PO 경유 검토 (PERS-REL-002 연동)

재검토할 것은 승인된 0~3장·인지/동의 기본 원칙이 아니라 **실제 후보 점수와 장면이 관계 의미를 왜곡하는지**이다.

- 다정한 + 도움 우선에도 거절/자기 휴식·피로 경계가 유지되는가?
- 욱하는 + 인지한 누락 확인 우선이 악의·배신·새 conflict를 생성하지 않고, 설명 수용 가능성을 남기는가?
- 고집 센 + 기준 설명/증거 검토가 사실 부정·영구 거부로 이어지지 않는가?
- 독립적인 + 휴식/자기 작업 우선이 무관심·낮은 애정으로 처리되지 않고 합의된 도움을 허용하는가?
- 6개 두장 조합과 회복 후 거리 유지, 쟁점 해결 vs 기억/감정 회복 분리의 반례가 충분한가?
- 성격만으로 공정성 `high=포함` 식 고정 입장 매핑을 하거나 250 갈등을 확정하는 오류가 없는가?

**필요 회신:** 카드별로 수용/보완/금지 조항, 실제 정연우 정의와 충돌하는 후보 조건/상한, PERS-REL-002의 미결 목록만. 새 severity/delta가 필요하면 독립 CR.

## C. 김플레이님에게 김PO 경유 협업 요청 (PERS-PLAY-001 연동)

- 4종 단독 + 두장 6조합을 **현재 지원되는 생활 후보**에 연결. 실제 없는 수리·재료 위치 전달·독심술·고의 단정 대사 금지.
- 각 장면마다 `source knowledge`, 권한, 행동/대상 반응, 거절, 대체 휴식/작업, 대화 없이 종료를 포함.
- `credit_ask`는 본인이 누락 기록을 안 뒤에만. `credit_fixed/ack`는 게시·전달 commit 이후. 기존 5개 record 대사 키는 **대사/발화 키이며 카드 행동을 자동 구현하는 것은 아님**.
- 카드 느낌을 대사만으로 완성했다고 주장하지 않고, 행동 선호가 실생활에서 어떤 순간에 드러났는지 5분·30분·재방문 장면에 반영.
- 첫4종의 독자성이 낮으면 카드 수보다 후보·필요·기억·거절 후 생활을 개선하는 방향 제안.

## D. 김디자인님에게 김PO 경유 전달

**필수 UI 상태:** 카드 없음(0/3), 카드 추가 1/3·2/3·3/3, 3장 뒤 추가 제한, 지원되지 않는 후보 미노출/선택불가, 카드 중복 방지, 기존 폰 편집, 변경 미리보기·취소·저장 완료·저장 실패·복구. 카드 얼굴/표정을 좋음/나쁨 등급처럼 표기하지 않음.

**말풍선:** 유효한 실제 행동 때만; 상대 미인지 사실·타인 비공개 기억을 노출하지 않음. 겹침/빠른 연속 발화/일시정지에서 읽힘 확인. 신규 아트 파일 크기·레이어 사양은 김도현의 실제 렌더 요구를 김PO가 취합한 뒤 확정.

## E. 김PO님께 이번에 결정 요청하는 **미승인** 항목

1. 임시 후보 점수표(+/-)와 1:1/2:1/4 감쇠, ±14 상한을 **실험 가설**로 채택할지.
2. 새로운 설명/기준 검토 행동 중 시제품 필수로 만들 범위(현 최신 코드 확인 후 결정).
3. 대상 독립 수락의 추가 점수/확률은 첫 시제품과 분리할지(권고: 예, 기존 반응 게이트 유지).
4. 현재 구현된 원인 사건과 인지/동의/기억의 우선 계약을 카드 변경 시에도 보존하는 QA 게이트 승인.

**절차:** 김시스템 → 김PO 검토·지시 → 각 담당자 회신 → 김PO 통합 승인 → 김도현 실행·증거 제출. 이 문서만으로 자동 발송·승인·통과된 것으로 기록하지 않음.
