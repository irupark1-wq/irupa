# PO-PERS-002 v1.1 — 관계 의미 정정·시스템 시험안 보완

- 김PO / 2026-10-14
- 원문: PO-PERS-002 v1.0. 보완 근거: PERS-REL-002·PERS-SYS-001 및 PO-HAND-016.
- 본 문서에 정정하지 않은 v1.0 조항과 PERS-C01~12는 유지한다. 전체 제작 우선순위는 PO-HAND-015·016을 따른다.

## 1. §1 문구 정정

‘모든 행동은 상대를 필요로 하지 않아야 한다’를 다음으로 대체한다.

**폰의 생활 진행은 상대 없이도 지속할 수 있어야 한다. 사회적 행동에는 상대의 독립 응답과 위치·동의·권한 조건이 적용된다.**

실제 지원되는 혼자 휴식/작업으로 생활을 이어가며 유효 후보가 없으면 안전한 idle을 허용한다. 이름뿐인 미지원 탐색 행동을 완료 사건으로 남기지 않는다.

## 2. §4 싫지만 협력의 금지 결과 정정

‘협력=사랑 증가·일괄 차단’을 다음으로 대체한다.

**공존/공동작업 참가만으로 자동 친밀·연애·갈등 해소가 발생하지 않는다. 실제 승인된 완료·인지 사건의 observer 방향 관계 기여는 기존 정의대로 평가한다. 낮은 애정만으로 모든 협력을 차단하지 않는다.**

EVT-04 등 기존 승인된 사건의 효과를 이 문구로 폐지하지 않는다. 후보·제안·수락·완료·인지·태그 판정을 구별한다.

## 3. §3 시험 수치와 진행 중 편집 보완

PERS-SYS-001 v1.0의 후보별 점수와 합성(1:1/2:1/4, 절댓값 내림차순, 카드 ID 동률, 마지막 half-away-from-zero 반올림, ±14)을 실험안으로 채택한다. 기본 점수 단위를 대조한 뒤 적용한다. 기존3축·관계 계산·상대 수락 게이트를 변경하지 않는다. 추가 반응 점수는 보류한다.

카드 편집은 이미 시작된 intent의 당시 snapshot을 바꾸지 않고 다음 새 선택부터 적용한다. 권한 철회와 안전 중단은 우선한다. 새 카드가 과거 source replay에 소급 적용되지 않는다. 상세 결정·게이트는 PO-HAND-016 §2~3이다.

## 4. §5 갈등250 참조 보완

정책 승인 근거는 PO-HAND-009 §2의 CR-DEV25-CREDIT-01~03이다. 소스 EventDefinition의 실제 ID/version·현재 활성 상태·실행 검수는 김도현이 제출한다. 정책 채택과 구현 활성화는 다른 상태이며 카드 도입이 자동 활성화 근거가 되지 않는다.

## 5. 다음 플레이 검수

첫4종이 모두 실제 후보 차이를 갖고, 고집 센의 근거 검토·수용과 욱하는의 근거 있는 확인이 동작해야 전체 완료다. 기존 휴식/도움 등만 연결한 G-PERS-1은 중간 납품이다. 디자인만 완성됐거나 말풍선만 달라지면 전체 게이트를 통과시키지 않는다.
