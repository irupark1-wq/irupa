# PO-14 — A1 공간 세부계획서

- 작성: 김PO / 수신: 김도현 / 참조: 김디자인
- 작성일: 2026-10-13 / 버전: v1.0
- 관련: PO-PLAN-001, PO-DEC-001, 김도현 A1 세부기획 요청
- 문서번호: 개발자가 요청한 PO-14를 유지한다. 파일 순번 17은 문서번호가 아니다.
- 상태: A1 제작 기준. 실제 실행·통과·외부 발송 완료와 별개.

## 1. 목표

가구를 옮기거나 장애물을 놓으면 폰의 이동·활동·만남이 실제로 달라지는 2D 공간을 만든다. 그림과 이동 판정이 맞고, 배치 전 가능 여부를 알 수 있으며, 실패해도 기존 월드와 진행 상태를 잃지 않아야 한다. 다중 방·맵 확대·새 가구 콘텐츠는 이번 A1에 추가하지 않는다.

## 3. 배치 조작과 안전 조건

기존 이동/닫기/장애물 기능을 재사용한다. 상세 입력 방식은 개발자가 현재 UI에 맞춰 구현하되, 가구/장애물 선택 → 위치 미리보기 → 확정 또는 취소가 명확해야 한다. 세로·가로에서 선택·배치·취소가 모두 가능해야 한다.

- 확정 전 미리보기는 확정 배치·저장 상태를 바꾸지 않는다. 편집 중 생활을 일시정지하며 편집 종료 후 자동 재개하지 않는다. 사용자가 재개한다.
- 경계 밖, 다른 가구/장애물과 겹침, 폰이 현재 서 있는 칸, 장애물 30칸 초과는 거절한다. 장애물 제거 및 가구 재이동으로 복구할 수 있다.
- 신규 배치로 폰을 갇히게 하거나 열려 있는 활동 지점을 완전히 고립시키는 경우 거절한다. 임시 폰 점유를 영구 장애물처럼 계산해 정상 배치를 막지 않는다. 실제 경로 비교에서는 점유를 계속 적용한다.
- ‘장소 닫기’는 해당 활동을 비활성화하는 기존 기능으로 유지한다. 모든 장소를 사용 가능하게 강제하지 않으며 닫힘 상태와 통로 막힘은 다르게 표시한다.
- 이동 중 목표 위치가 바뀌면 재개 시 새 경로를 계산한다. 폐쇄·도달 불가·대상 이탈은 안전 취소/대체 행동이며 완료 사건과 관계 벌점을 만들지 않는다.
- 확정은 현재 배치 버전에 대한 저장 성공 후 적용한다. 실패·충돌은 원본을 유지하고 미리보기 초안을 보존해 재시도/취소할 수 있게 한다. 버전 충돌을 자동 덮어쓰지 않는다.
- 그림의 가구 중심·활동 칸·장애물 범위를 일치시킨다. 시각적 장식과 사용 가능한 장소를 구분한다.

초기 배치는 개발자가 현재 실행본의 좌표를 제출하고, 위 조건을 만족하면 유지한다. 현재 좌표를 확인하지 않고 새 좌표를 임의 지정하지 않는다. 미래 방문 입장 위치는 예약/참조 지점을 개발자가 제안하되 A1에서 온라인 입장 완료를 요구하지 않는다.

## 4. 안내 문구 및 표시

유효 위치에는 윤곽과 ‘여기에 놓을 수 있어요’를, 무효 위치에는 윤곽/아이콘과 이유를 함께 표시한다. 색만으로 상태를 구분하지 않는다.

| 상황 | 기본 문구 |
|---|---|
| 경계 밖 | 방 안에 놓아 주세요. |
| 가구/장애물 겹침 | 여기는 다른 물건이 있어요. 다른 칸을 골라 주세요. |
| 폰이 있는 칸 | 폰이 있는 칸이에요. 다른 칸을 골라 주세요. |
| 통로 차단 | 길이 막혀요. 폰이 지나갈 칸을 남겨 주세요. |
| 장애물 상한 | 장애물은 30칸까지 놓을 수 있어요. 다른 장애물을 먼저 지워 주세요. |
| 장소 닫힘 | 이 장소는 지금 닫혀 있어요. |
| 권한 없음 | 이 월드는 주인만 배치를 바꿀 수 있어요. |
| 저장 실패 | 배치를 저장하지 못했어요. 다시 시도하거나 취소해 주세요. |
| 버전 충돌 | 배치가 다른 곳에서 바뀌었어요. 최신 배치를 확인해 주세요. |

저장 실패 설명은 실제 데이터 상태와 맞춰 표시한다. 사용자에게 내부 오류 코드만 보여주지 않고 개발 증거에는 원인을 남긴다.

| ID | 실제 조작 | 통과 기준 |
|---|---|---|
| A1-01 | 기본 월드에서 폰 3명 생활 관찰 | 그림·활동 칸·점유·이동 위치 일치, 선택지 없이 생활 진행 |
| A1-02 | 작업대 위치 미리보기 후 취소 | 원래 배치·저장 자료 유지, 관계/기억 변화 없음 |
| A1-03 | 유효 위치로 작업대 이동·저장·재개 | 새 위치로 경로/활동 반영, 기존 위치에서 작업 완료 처리 없음 |
| A1-04 | 경계 밖·겹침·폰 칸에 배치 시도 | 이유 표시, 확정/저장 거절, 원본 유지 |
| A1-05 | 통로를 완전히 막는 장애물 배치 시도 | 경고 및 거절. 정상 우회가 남는 배치는 허용하고 경로 반영 |
| A1-06 | 활동 장소 닫기/다시 열기 | 이동/활동 안전 취소·대체, 점유 해제, 허위 완료·감정 벌점 없음 |
| A1-07 | 장애물 배치·제거·30칸 초과 | 개수와 실제 충돌 일치, 초과 거절, 제거 후 경로 복구 |
| A1-08 | 저장 실패 및 버전 충돌 주입 | 원본 보존·초안 재시도/취소, 중복 반영 없음 |
| A1-09 | 저장 후 종료·재실행 | 같은 가구/장애물/폰 상태 복구, 생활 정지, 효과/사건 재실행 없음 |
| A1-10 | 세로·가로 전환 | 월드 좌표와 배치 동일, 편집/관찰/취소 조작 가능 |
| A1-11 | 비소유자 배치 변경 시도 | UI와 상태 변경 함수 모두 거절. 로컬 권한 검증은 온라인 보안과 구분 |
| A1-12 | 폰 48/64/96px·밝음/어두움·가구 가림 확인 | 원형/얼굴/선택 대상 식별 가능, 비교 결과와 미완료 목록 제출 |

검증 환경은 김도현이 현재 지원 환경과 실제 세로·가로 화면 크기를 명시한다. 모든 기기 지원으로 확대하지 않는다. 특정 크기에서 조작 불가하면 미완료로 기록한다.

## 6. 담당별 요청과 납품

김도현은 초기 배치 좌표, 실제 렌더링 크기, 배경/가구 분리 자산에 필요한 해상도·파일명·확장자·투명 배경·기준점·점유 범위를 김PO에게 요청한다. 김PO가 김디자인에게 전달한다. 이 문서가 임의 픽셀 규격을 지정하지 않는다. 김디자인은 실제 grid와 일치하는 자산 및 상태 시안, 축소·가림 검수 자료를 납품한다.

김도현 납품: 실행본/방법·버전 또는 commit·지원 화면 크기·A1-01~12 결과표·실제 출력/화면 기록·실패 및 미실행·타입검사/CI 상태·다음 필요한 세부기획 요청. 통로 판정·멱등성·저장 실패는 결과를 검증하는 의미 있는 검사로 확인한다.

김PO는 실제 체험과 증거를 보고 통과/조건부 보완/미통과를 판정한다. A1 통과는 관계 A2·온라인·전체 게임 완료를 뜻하지 않는다. 본 계획에 새로 추가된 조건이 현 코드와 충돌하면 김도현은 영향과 대안을 문서번호 PO-14로 회신한다.
