- 작성: 김PO / 수신: 김도현 / 참조: 정연우·김시스템·김플레이·김디자인
- 작성일: 2026-10-14 / 버전: 1.0
- 사용자 결정: 다음 개발은 정연우의 캐릭터 성격 설계를 우선한다. 성격과 관계가 게임의 핵심이다.
- 기준: PO-PERS-001 v1.1, 정연우의 첫4종 관계 검수 v1.0, PO-HAND-014, PO-PERS-002.
- 상태: 제작 우선순위 변경·착수 지시. 구현 완료·실행 검증·팀원 자동 발송 기록이 아니다.

## 1. 우선순위 변경

다음 플레이 가능한 개발 묶음의 중심을 **성격 카드 4종의 실제 자율 행동과 관계 반응**으로 변경한다. 기존 문서의 로그인·두 방을 카드보다 먼저 계속 확장하는 순서는 본 지시로 대체한다. 이미 배포한 로그인·두 방·저장 기능은 유지한다.

개발 순서는 다음과 같다.

1. 기존 행동 후보·인지·기억·수락 처리에 카드 적용 지점을 연결한다. 필요한 PERS-SYS-001·PERS-PLAY-001 정본과 미지원 행동을 확인한다.
2. 첫4종을 실제로 선택·수정·저장하고 생활시키는 작은 버전을 만든다. 대사만 바꾸는 구현은 완료로 보지 않는다.
3. 상황에 따른 도움·거절·확인·설명 수용·혼자 활동과 말풍선을 연결한다. 상대 반응은 독립적으로 처리한다.
4. 복합 성격과 관계·기억 차이를 검증하고, 승인된 국소 분쟁·정정·회복과 연결한다.
5. 대표 생활 장면과 저장 호환 증거를 김PO에 제출해 다음 확장 여부를 판정한다.

로그인 실기 잔여 시험과 데이터 손실·권한 결함은 병행 처리한다. 데이터가 손상되는 결함은 성격 기능보다 먼저 수정한다. Google 공개 전환·유료 서비스·전체 배경 12종 양산·신규 방·온라인 확장은 이번 핵심 개발의 선행 조건이 아니다. 배경 3종 시제품은 별도로 진행하되 성격 작업을 기다리게 하지 않는다.

## 2. 정연우 우선의 의미

정연우가 정의한 성격의 의미, 사실 인지, 기억, 거절, 쟁점과 갈등의 경계를 우선 적용한다. 김시스템은 이를 구현 가능한 후보 점수·합성·상한으로 바꾸고, 김플레이는 실제 생활 장면과 발화를 보완한다. 최종 제품 결정과 개발 인계는 김PO가 담당한다.

새 카드를 이유로 기존 관계 점수·갈등 severity를 직접 수정하지 않는다. 수치 변경이 필요하면 별도 CR과 원인 사건·검증 근거를 제출한다. ‘욱함=싸움’, ‘독립적=차가움’으로 단순화하지 않는다. 동시에 모든 폰이 같은 친절한 반응을 보이는 문제도 통과시키지 않는다.

## 4. 완료 판정

다음 버전은 4종 모두 최소1개 행동 후보/우선순위 차이가 있고, 실제 생활에서 대표 차이가 관찰되어야 한다. 말풍선만 다르거나 무조건 수락/싸움을 시키면 반려한다. 기존 PERS-C01~12를 유지하고 PO-PERS-002의 장면을 시험 증거로 연결한다.

김도현은 최신 커밋·규칙 버전·입력/seed·후보 차이·최종 행동·상대 반응·관계 원인 사건·저장/복구 결과를 제출한다. 실제 구현과 기획 예시를 구별한다. 3.5일이라는 이전 추정은 참고값이며 이번 범위의 일정은 개발자가 갱신한다. 검증 완료 전 출시 일자를 확정하지 않는다.

이번 게이트가 통과한 뒤에만 다음 성격 확장과 추가 관계 콘텐츠를 결정한다. 첫4종이 재미있게 작동하기 전에는 카드 수를 늘려 다양성을 대신하지 않는다.
