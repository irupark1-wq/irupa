# REL-03 정연우 → 김도현 (김PO 참조): A2 관계 서사 REQ-01 사전 검수 회신

- 수신 경로: 김PO 가 채팅으로 전달(2026-10-13). 원문을 그대로 옮김.

검토 결과, 반복 상한의 행동/효과 분리와 Day 초기화 방향을 수용합니다.

## 1. 반복 상한

* 행동 가능 여부와 관계 효과 가능 여부는 독립 판정합니다.
* 게임 Day 변경 시 효과 횟수만 초기화합니다.
* 완료됐지만 효과 제한에 걸린 인사·대화는 효과 0의 사건 기록으로 남깁니다.
* 이러한 사건은 태그의 유효 긍정 사건으로 세지 않습니다.
* 갈등·정정·복구에는 일일 상한을 적용하지 않지만 고유 증거·멱등성 검사는 반드시 유지합니다.
* 늦게 알게 된 사건은 원래 발생한 게임 Day 기준으로 재투영합니다.

## 2. STORY-C

공동작업 완료, 실제 기여, 합의한 공로 기준, 게시 결과를 확인할 수 있을 때 불일치 사실을 생성합니다. 고의는 별도 증거가 없는 한 미확인입니다.
EVT-09는 실제 정정과 전달·인지가 확인된 경우, EVT-12는 특정 갈등의 복구 계획 이행과 필요한 수용 증거가 확인된 경우에만 생성합니다.

## 3. AUTO 검증

* AUTO-11: 낮은 애정·높은 존중 상태에서 자발적 협업 가능
* AUTO-16: 실질 복구 후에도 독립적인 거리두기 가능
* AUTO-22: 미해결 갈등 중 협력 가능, 사과·도움만으로 자동 화해 불가

각 사례는 초기 8축·성격·12×8 공간·seed를 고정하고, 허용 행동과 금지 행동을 함께 검사해 주세요.

## 4. 가벼운 위임

비민감한 게임 내부 작업 정보를 대상으로 수락·거절·이행·불이행을 별도 사실 사건으로 정의합니다.
수락 자체는 신뢰 상승이 아니며, 거절 자체는 배신이 아닙니다. 이행은 검증된 약속 완료, 불이행은 실제 기한·영향·사유를 확인한 뒤 관계 효과를 평가합니다.
