# PO-DES-REQ-003 — REQ-07 배경·가구 제작 의뢰

## 1. 목표와 1차 범위

아늑한 방의 따뜻한 목재·초록 식물·클로버·부드러운 빛을 참고해 생활방과 가구의 화풍을 맞춘다. 생활방은 함께 생활하고 일하는 공간, 아늑한 방은 쉬는 공간으로 구별한다. 폰과 말풍선·배치 칸을 쉽게 읽을 수 있어야 한다.

먼저 생활방 가로 배경의 아침·낮·밤 3종을 같은 구도로 제작한다. 쿠션 매트·클로버 러그·작업대·꽃상자 4종은 현재 원본과 새 시안을 비교할 수 있게 제출한다. 전체 UI 재설계는 이번 선행 작업이 아니다.

## 2. 최종 배경 납품 규격

| 구분 | 픽셀 | 파일명 |
|---|---|---|
| 생활방 세로 | 941×1672 | room-living-portrait-v2-{morning,noon,night}.png |
| 생활방 가로 | 1672×941 | room-living-landscape-v2-{morning,noon,night}.png |
| 아늑한 방 세로 | 941×1672 | room-cozy-portrait-v2-{morning,noon,night}.png |
| 아늑한 방 가로 | 1672×941 | room-cozy-landscape-v2-{morning,noon,night}.png |

중괄호는 3개 실제 파일로 풀어 납품한다. sRGB·불투명 PNG를 기준으로 하며 무손실 WebP 변경은 파일명 명세와 함께 협의한다. 이미지당 1.5MB 이하는 목표이며 화질을 망가뜨려 강제하지 않는다. 글자·숫자·폰 얼굴을 배경에 넣지 않는다. 배치 가능한 바닥에 이동 가능한 가구·러그·화분을 구워 넣지 않는다.

같은 방향의 3종은 한 원본 구조에서 조명·색·창밖·등불만 변경한다. 벽·바닥·문·가구 경계와 칸 대응이 시간마다 움직이면 안 된다. 조명 변화는 허용하므로 전체 픽셀 색 일치 대신 구조 경계·점유 영역의 일치를 검수한다.

## 3. 바닥과 장식 좌표

논리 맵은 각 방 12×8칸을 유지한다. 세로·가로 화면은 같은 배치를 보여준다. manifest에 이미지 크기, floor_rect, 칸 변환 기준, 고정 장식 셀 목록, 폰/가구 앵커, 가려짐 순서, 조명 위치를 적는다. 좌표 원점은 좌상단, 단위는 원본 이미지 px로 명시한다.

REQ-07의 현재 아늑한 방 기준은 세로 x70/y450/w810/h610, 가로 x330/y375/w1190/h385다. 이는 검수 출발점이며 최종 확정 도면이 아니다. 바꾸면 기존 대비 좌표와 이유를 제시하고 개발자 변환 검수 후 적용한다. 침대·책상 등이 실제 이동 바닥을 침범하면 그림을 옮기거나 고정 장식 셀로 명시한다. 이미지 교체만으로 통행 금지 셀을 추가하지 않는다.

## 4. 가구 4종

투명 PNG 약 512×512 작업 캔버스, 약 30도 시점으로 제작하되 개발자가 현재 원본 파일명·앵커를 확인하도록 대응표를 제출한다. 원본이 없으면 임의로 ‘기존 정본’이라 명명하지 말고 김PO에게 요청한다.

매트·러그는 중심 앵커, 작업대·꽃상자는 앞쪽 바닥 접점 앵커를 명시한다. 러그의 시각 폭 1.5~2칸, 작업대·꽃상자 1~1.3칸은 시안 목표다. 논리 점유는 기존 1칸을 유지하므로 인접 칸을 가려 배치 판정을 오해하게 만들면 시각 폭을 줄인다. 매트 위 폰이 앞에 보이는 레이어, 선택 테두리와 그림의 일치도 함께 확인한다.

## 5. 시간대 표현 규칙

- 06:00~11:00: 아침.
- 11:00~17:00: 낮.
- 17:00~19:00: 낮에서 밤으로 점진 전환.
- 19:00~다음 날 05:00: 밤.
- 05:00~06:00: 밤에서 아침으로 점진 전환.

이는 REQ-07의 미정 새벽 전환 시간을 보완한 PO 기준이다. 실제 전환은 게임 시계를 사용하고 정지 중 시각도 멈춘다. 동작 줄이기 설정에서는 지속적인 장식 모션을 멈추고 시간대 변경 시 정적인 상태를 표시한다. 야간에도 폰 윤곽·가구·말풍선·배치 불가 표시를 읽을 수 있게 한다. 낮/밤으로 이동 판정이나 관계 효과를 새로 만들지 않는다.

개발 적용 시 현재 방향·시간대 이미지를 먼저 읽고 전환에 필요한 다음 이미지만 추가로 준비한다. 12종을 첫 입장에서 모두 읽는 구조를 전제하지 않는다. 적용 전 로딩·메모리·전환 깜빡임을 김도현이 확인한다.

## 6. 제출물과 검수 게이트

1차 제출: 3종 배경, 4종 가구 비교표, 편집 원본, floor/장식 manifest, 동일 배치의 PC·폰 화면 목업, 변경사항과 미결정 항목. 목업은 실제 구현 화면과 구분한다. DES-14 정본을 함께 전달하거나 문서 부재를 명시한다.

합격 조건: 시간대 간 구조 동일, 빈 바닥과 고정 장식 구별, 폰/말풍선 가독성, 배치 그림과 논리 칸의 대응, 이동 패널을 포함한 장면 확인 가능, 기존 저장 배치 유지. 목업 합격은 실제 구현 시험 합격을 뜻하지 않는다.
