## 1. 진행 상태 갱신

SB-0005 적용·10/10 시험과 두 방/형식3의 neinom.com 배포를 **개발자 보고**로 기록한다. 이전의 ‘SB-0005 적용/두방 배포 대기’ 상태는 이 보고에 따라 갱신하되, 김PO의 실제 서버시험·사이트 체험을 수행한 것으로 표시하지 않는다.

DES-15의 민트 주 버튼·로그인/저장 상태 두 줄·아직 월드 없음·첫 방문 안내가 반영됐다는 보고를 접수한다. 민트 버튼은 현재 포근한 UI 방향과 맞는 적용안으로 수용하며 정확한 대비/크기/읽힘은 실제 화면 검수한다. ‘아직 월드 없음’은 실제 선택한 로컬/계정 범위의 조회가 완료돼 없는 경우에만 사용하고, 인증 중/조회 실패/비공개 계정 사본을 월드 없음으로 치환하지 않는다.

AUTH03·07·10·12의 실제 시험, ROOM10 가로·디자인 바닥/장식 검수, 개인정보 확인자료/공개문안은 이번 요약만으로 완료로 올리지 않는다.

## 2. 방 이동 패널 결정: 현재 방식 유지

**장면 아래 작은 패널과 큰 칸 보드를 유지한다.** 오른쪽 큰 이동 패널로 일괄 교체하지 않는다. 플레이어가 도착 방과 안전한 칸을 확인하는 것이 우선이며, 패널 크기 자체를 디자인 시안과 맞추기 위해 실제 공간을 가리지 않는다.

필수 표시/조작:

- 이동할 폰, 현재 방과 도착 방, 선택한 칸, 배치 가능/불가 이유.
- 미리보기·확정·취소를 분리하고 미리보기만으로 이동/저장하지 않음.
- 확정 전에 도착 방의 그림/장식·가구·다른 폰과 목표 칸을 확인 가능.
- 폰 세로/가로에서도 읽히는 터치 영역·칸 보드·확정/취소 접근성 유지. 색만으로 판정하지 않음.
- 이동 중 생활 정지, 취소/실패의 원 위치·점유 유지, 확정 후 자동 재개 없음.
- 안전 칸이 없으면 이유와 배치 수정/취소 제공. 큰 패널로 이를 숨기지 않음.

실제 작은 패널에서 문구·버튼이 잘리거나 월드/선택칸 연결이 불분명하면 레이아웃을 보완한다. 넓은 PC 화면의 오른쪽 패널은 **장면의 가용 영역을 충분히 유지하는 별도 비교안**으로만 검토한다. 현재 제작을 바꾸는 선행 조건이 아니다. 같은 선택/판정/저장 함수와 상태 계약을 유지한다.

김디자인은 DES-15와 현 구현의 차이를 ‘기능 계약 차이’와 ‘배치 표현 차이’로 나누어 회신한다. 본 제품 결정이 해당 항목의 최신 기준이며 시안만을 근거로 구현을 되돌리지 않는다.
