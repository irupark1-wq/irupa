## 2. DES-15 반영 (시작 화면)

| 항목 | 처리 |
|---|---|
| 주 버튼 "이 기기에서 시작하기"·"이어서 하기" 민트색 | 반영 |
| "이메일로 계속하기"는 테두리 보조 버튼 | 반영 |
| 로그인 상태·월드 저장 위치 두 줄에 아이콘 | 반영. 저장 위치는 구름이 아니라 폴더 아이콘(시안 메모: 구름은 계정 저장으로 오인) |
| 이 기기에 월드가 없을 때 "이 기기에 저장됨" 대신 "아직 월드 없음" | 반영(PO-START-001 §6 빈 로컬과 맞춤) |
| 첫 방문 안내 "시작하면 이 기기에 저장돼요" | 반영(이어서 하기 화면에서는 숨김) |
| 방 전환 버튼에 생활방(집)·아늑한 방(달) 아이콘 | 반영 |
| Google 버튼 | 공식 버튼 규격 유지(시안 메모와 같음) |
| 방 이름 "거실" | 김PO 결정대로 "생활방" 유지 |
| 성격 카드 시안 | 보관만. PERS-SYS-001 계수 도착 후 카드 화면 만들 때 사용 |
| 시안의 폰 그림 | 참고만. 폰 얼굴은 플레이어가 그림 |
