## 1. 두 번째 방 (PO-ROOM-001)

| 더 새 형식 | 계속 거절, 원본 그대로 |

### 1.2 생활 규칙

- 시계·Day·반복 자격(하루 3회·60틱)·관계·공로 흐름은 월드 공유. 방을 바꿔도 quota 가 초기화되지 않습니다(ROOM08).
- 경로·후보·대화·도움·함께하기·**목격**은 같은 방 안에서만. 다른 방 폰끼리 원격으로 만나지 않습니다(ROOM07, 1500틱 시험).
- 기록판은 방마다 있습니다. 도움 원천에 방을 남기고, 그 방 기록판에서만 적고·읽고·고칩니다.
- 방문 폰은 생활방에 머물고 옮기지 않습니다.

### 1.3 폰 옮기기

| 단계 | 동작 |
|---|---|
| 시작 | 폰 상세 → "아늑한 방으로 옮기기"(또는 "생활방으로…") → 생활 정지 → 도착 방을 보여 줌 → 안전한 빈칸 하나를 제안 |
| 고르기 | 칸 판 또는 바닥을 눌러 미리보기. 거절 이유: 그림 속 장식 / 다른 물건 / 다른 폰 / 길 막힘 / 방 밖 / 이미 이 방 / 내 폰 아님. 안전한 칸이 없으면 "폰이 설 자리가 없어요. 빈칸과 통로를 만들어 주세요." |
| 확정 | 한 commit: 원래 방 활동을 중립 취소(완료·관계 효과 없음, 짝도 풀림) + 도착 위치. 받아들인 약속·역할은 그대로. 같은 명령 재전송은 같은 결과(ROOM03·06·09) |
| 취소 | 원래 방·자리 그대로. 자동 재개 없음(▶ 로 재개) |

### 1.4 화면

- 상단 방 전환(생활방 N · 아늑한 방 N). 보기 전환은 폰을 옮기지 않습니다. 좁은 화면에서는 두 번째 줄로 내려가고 카메라가 그만큼 비킵니다.
- 보고 있는 방의 가구·장애물·폰만 그립니다. 빈 방이면 "아직 이 방에 폰이 없어요. 폰을 옮겨 함께 지내게 할 수 있어요."
- 배치 모드는 보고 있는 방을 편집합니다(방별 저장·버전). 고정 장식 칸은 지우거나 덮을 수 없습니다(ROOM04).
- 증거 `docs/evidence/rooms/`: PC 생활방·아늑한 방(빈 방)·옮기기 미리보기·옮긴 뒤 두 방 동시 생활, 폰 세로 아늑한 방.

## 2. 로그아웃 격리 (PO-DEC-007 §4) — 배포됨

이전 동작에는 PO 지적대로 차이가 있었습니다. 연결 기록만 지웠고, 계정에서 불러온 월드는 로그아웃 뒤에도 게스트 화면에 그대로 보였습니다. 이렇게 고쳤습니다.

- 계정에서 불러온 월드에 출처(어느 계정)를 표시합니다.
- 로그아웃할 때 그런 월드가 있으면 고르게 합니다: **이 기기에 사본 남기기** / **이 기기에서 지우기(계정에는 그대로)**. 지우면 불러오기 전에 있던 이 기기 월드를 되돌립니다(없으면 빈 기기).
- 시작 화면: 그 계정으로 로그인하지 않았으면(게스트·확인 중·다른 계정) 폰 이름·제목을 숨기고 이어하기 대신 "불러온 계정으로 로그인하면 이어할 수 있어요" + "이 기기의 계정 사본 지우기".
- 다른 계정에서 불러온 월드는 지금 계정에 저장하지 않습니다(실수 업로드 방지).
- 파일 불러오기·새 월드·원본 보관 후 새로 시작은 출처 표시를 지웁니다.
- 시험: 단위(AUTH10 mock, START08) + 로컬 화면(잠김·이름 숨김·지우기). 실기는 3절 AUTH10.

다른 브라우저에서 메일 링크를 연 경우: 복귀 페이지가 "이 브라우저에서는 로그인을 마칠 수 없었어요. 메일 확인을 마쳤다면 게임에서 이메일과 비밀번호로 로그인해 주세요."로 안내합니다. 토큰을 복사하게 하지 않습니다. 실기 확인은 3절에 넣었습니다.

## 4. 성격 카드 저장 계약 (PO-HAND-011 §2)

| 필드 | 뜻 |
|---|---|
| `schema` | 1 |
| `rule_version` | `game1-cards-inactive-v0`(효과 없음 표시) |
| `profile_version` | 카드 묶음이 바뀔 때마다 +1 |
| `card_ids` | 정렬된 목록, 0~3장, 지원 4종(kind·hot_tempered·stubborn·independent)만, 중복 불가 |
| `effective_from_order` | **authority 순서 번호**(같은 tick 안 여러 변경도 순서 구분) |
| `active` | false(계수 확정 전 효과 없음) |

- 보존: 카드가 바뀌면 이전 묶음을 `card_history` 에 쌓을 계획입니다. 지울 때는 생활 기록(trace)·사건에서 아직 참조하는 `profile_version` 은 남기는 규칙으로 하겠습니다(지금은 바꾸는 기능이 없어 비어 있음).
- 효과 위치(계수 확정 후): 생활 후보 점수(다정한·독립적인), 행동별 수락 응답(독립적인의 대화 응답 등), **공로 흐름의 응답**(욱하는 = 확인 부탁 의사·시점, 고집 센 = 설명을 받아들이는 응답). 관계 원장의 감정 기여·수락 하드 조건·인지·사실 증거에는 닿지 않습니다.
- PERS-SYS-001·PLAY 안 전에는 계수를 넣지 않고, 일반 화면에 카드 선택을 보이지 않습니다.
