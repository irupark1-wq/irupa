## 1. 승인

**두 장 모두 확정입니다. 이 룩으로 갑니다.** 가로·세로 배치, 명판·시계·속도, 하단 독 7버튼, 폰 상세 패널(가로는 오른쪽, 세로는 아래 시트), 말풍선, 활동 지점 매트, 바닥에 놓인 "이야기 자리" 클로버까지 그대로 코드에 옮깁니다.

특히 좋았던 점 — 상단이 명판·시계만으로 정리된 것, 필요 막대 위 한 문장("누군가와 이야기하고 싶어요"), 말풍선 안에 작은 아이콘이 들어간 것, 세로에서 상세가 아래 시트로 내려온 것.

개발 쪽에서 시안과 다르게 갈 것은 **한 가지뿐**입니다. 게임 속 폰 얼굴은 플레이어가 직접 그립니다. 그래서 시안의 하니(고글)·노을(클로버 머리)·모래·선은 게임에서 **"참고 예시" 얼굴**로만 쓰이고, 플레이어가 그린 폰이 그 자리에 들어갑니다. 폰 만들기 버튼의 웃는 폰 아이콘은 그대로 씁니다.

## 2. 왜 파일이 더 필요한가 (두 줄)

받은 두 장은 완성 **사진**이라, 폰을 움직이거나 글자를 바꾸거나 버튼을 누른 모양으로 만들 수 없습니다. 게임은 **레고**처럼 배경·폰·말풍선·버튼 조각을 코드가 쌓아 올립니다. 그래서 **같은 그림을 조각별로 따로 저장**해 주셔야 합니다. 새로 디자인하는 것이 아니라 저장 방법의 문제입니다.

## 4. 조각 파일 만드는 법 (요약)

- **AI 도구(ChatGPT·Midjourney)**: 요소 하나만 **흰 단색 배경**에 생성 → 배경 제거(remove.bg, 포토샵 "배경 제거", 피그마 "Remove BG") → 표의 크기 정사각 캔버스에 저장. 같은 묶음은 **한 대화에서 연속 생성**하고 첫 장을 붙여 "same style as this". 프롬프트 끝에 늘: *"single object only, centered, plain white background, no text, no watermark, soft storybook sticker style matching the reference"*.
  - 배경 2장: 승인된 시안을 붙이고 *"same room, same style, remove all characters, speech bubbles, floor mats, UI and text; keep the floor completely empty"* + 크기(1920×1080 / 1080×1920).
  - "빈 것"으로 표시한 판·타일·말풍선: *"empty [cream rounded plate / blue rounded tile / white speech bubble], no icon, no text, sticker style, white background"*.
- **포토샵·프로크리에이트·클립스튜디오·피그마**: 배경 레이어 끄고 PNG(투명) 내보내기. 원본 파일도 `_source/`에.
- **투명 확인**: 저장한 PNG를 **검은 바탕에** 올려 가장자리에 흰 띠가 없으면 통과. JPG 저장 금지.
- 폴더 구조는 표대로 만들어 **zip 하나**로. 다 못 만들어도 ★부터 보내 주세요.

## 5. 통과 기준

1. 검은 바탕에서 흰 띠 없음 2. 글자 없음(로고 제외) 3. 배경 2장의 빈 마루에 가구·무늬 없음 4. 두 배경이 같은 방으로 보임 5. 독 아이콘 7개를 42px로 줄여도 구분됨 6. 같은 묶음끼리 그림체·그림자 방향 같음.

## 6. 결정 기록

- **확정:** 시안 01·02 룩. 세로 9:16 + 가로 16:9. 폰 상세 탭은 시안대로 3개(현재 상태·관계 요약·기억); 성격·상세 정보는 "얼굴·성격 꾸미기"와 더보기로 이동. 폰 얼굴은 플레이어 그림, 시안 캐릭터는 참고 예시.
- **가정:** 빈 마루 비율은 추정값, 배경이 오면 실기기에서 조정. "빈 것" 판·타일이 안 오면 코드가 그립니다(시안 색을 뽑아서).
- **확인 필요:** 글꼴, H항목 가능 여부.
