## 5. 보관·삭제·복구 — 실제로 되는 것과 안 되는 것

| 요청 | 지금 지원 |
|---|---|
| 계정에 저장한 월드 지우기 | **됨**: 더보기 → 계정 → 계정 월드 목록 → "계정에서 지우기"(즉시 서버에서 삭제) |
| 이 기기 월드 지우기 | 브라우저 자료 삭제로 가능. 게임 안 "전체 삭제" 버튼은 없음 |
| 계정 자체 삭제(로그인 정보 포함) | **게임 안에서는 안 됨**. 문의 메일 → 운영자가 Supabase 대시보드에서 사용자 삭제 → 연결된 프로필·계정 월드가 함께 삭제(데이터베이스 cascade, 확인됨). 처리 기간은 김PO 가 정해야 함 |
| 비밀번호 잊음 | 재설정 메일(이메일 계정) |
| 서버 백업 보관 | Supabase 요금제의 자동 백업 정책을 따름 — **확인 필요**(Free 요금제 백업 범위). 게임이 별도 백업을 만들지 않음 |
| 메일 발송 기록 보관 | Resend 정책 — **확인 필요** |
| 즉시 완전 삭제 약속 | 하지 않음(서비스 로그·백업 보관 기간이 남을 수 있음) |
