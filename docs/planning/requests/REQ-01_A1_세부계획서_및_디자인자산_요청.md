## 3. 정연우 께 전달 부탁 — 검수 요청 (REL-03 으로 회신 요청)

1. DEV-19 3절 "반복 상한" 제안(행동 가능 여부와 효과 제한 분리, 게임 하루 리셋, 효과 0 사건 기록) 검수.
2. STORY-C 최소 증거 필드(joint_work_id, contribution_refs, attribution_rule_id, published_credit_refs, correction_action_id, repair_plan_id)가 "무엇을 담아야 사유 미확인/정정/복구로 인정되는지" 한 줄씩.
3. AUTO-11(싫지만 협력)·16(회복 후 거리두기)·22(갈등과 화해 분리)의 기대값을 입력(관계 초기값·성격·공간)과 출력(어떤 행동이 나와야/나오면 안 되는지)으로 구체화.
4. "가벼운 위임(정보 맡기기)" 의 최소 정의: 무엇을 맡기고, 수락·거절·이행·불이행이 어떤 사건이 되는지.
