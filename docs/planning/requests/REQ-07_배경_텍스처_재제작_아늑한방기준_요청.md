# REQ-07 배경·UI 텍스처 재제작 요청 — "아늑한 방" 기준으로 통일 (김디자인)

- 문서번호: REQ-07 / 작성: 김도현 / 받는 사람: 김PO (김디자인님께 전달 부탁) / 날짜: 2026-10-13 / 상태: 요청
- 근거: 사용자(제품 책임) 의견 2026-10-13. "지금 배경과 UI 가 통일성이 없고 어색하다. 아늑한 방을 기준으로 배경 텍스처를 다시 만들자. 예전 카펫 같은 가구도 다시 살리자."
- 관련: REQ-06(아늑한 방 바닥 검수, 대기), DES-06(생활방 장식 배경), DES-15(시작 화면 시안), PO-ROOM-001, PO-HAND-012 §3(PO-DES-REQ002)

## 1. 왜 다시 만드나

지금 게임에는 그림체가 다른 세 가지가 섞여 있습니다.

| 부분 | 지금 그림 | 문제 |
|---|---|---|
| 생활방 배경 | DES-06 장식 배경(밝은 크림 벽, 단순한 마루) | 아늑한 방보다 단순하고 평면적이어서 두 방이 다른 게임처럼 보임 |
| 아늑한 방 배경 | 예전 "아늑한 방"(`assets/legacy-room/background-room-*.png`) | 따뜻한 빛·덩굴·나무 질감이 풍부함 → **이것을 기준 그림체로 삼음** |
| 가구 | 2026-10-13 부터 예전 러그·매트·작업대·화분 상자 그림을 다시 씀(`assets/legacy-room/furniture-*.png`) | 아늑한 방과는 잘 맞지만 생활방 배경과는 결이 다름 |
| UI 틀(명판·독·패널·탭) | 나무 독·크림 패널 | 배경 질감과 색 온도가 조금씩 다름 |

목표: **두 방 배경, 가구, UI 틀이 한 세계처럼 보이게** 아늑한 방의 그림체(따뜻한 오후 빛, 꿀색 마루, 초록 덩굴·클로버, 나무·바구니 질감)로 맞춥니다.

## 2. 요청 자산

### 2.1 생활방 배경 새 판 (필수)
아늑한 방과 같은 그림체로 다시 그린 생활방. 침실 느낌인 아늑한 방과 구분되게 **거실/생활 공간**(창가, 소파 대신 벽 장식, 작은 화분, 액자 등)으로 해 주세요.

| 파일명(제안) | 크기 | 형식 |
|---|---|---|
| `room-living-portrait-v2.png` | 941×1672 | sRGB PNG(또는 무손실 WebP), 불투명 |
| `room-living-landscape-v2.png` | 1672×941 | 같음 |

- 이동 바닥(폰이 걷는 12×8 칸)은 **넓고 비어 있게**. 바닥 위에 그림으로 가구·러그·화분을 그리지 않기(가구는 게임이 칸 위에 따로 놓음).
- 바닥 사각형(원본 픽셀 x,y,w,h)과 여유 포함 보호 구역을 manifest 에 적어 주세요(DES-06 형식 그대로). 세로·가로에서 같은 칸이 같은 자리처럼 보이게.
- 장식은 벽·창가·바닥 사각형 바깥 가장자리에만. 폰보다 눈에 띄지 않게(케이티정 원칙 2).
- 그림 안에 글자·숫자·간판·캐릭터 금지(원칙 4). 광원(창·조명) 중심 좌표를 manifest 에.

### 2.2 아늑한 방 배경 정리판 (필수, REQ-06 과 합쳐 처리 가능)
지금 아늑한 방은 바닥 가장자리에 난간·화분이 걸쳐 있고 원본이 A1 칸 규칙 전에 그려졌습니다. 같은 그림을 바탕으로 **바닥 사각형만 깨끗이 정리**한 판을 부탁드립니다. 새로 그리기보다 편집을 권합니다.

| 파일명(제안) | 크기 |
|---|---|
| `room-cozy-portrait-v2.png` | 941×1672 |
| `room-cozy-landscape-v2.png` | 1672×941 |

- 지금 개발이 쓰는 바닥 사각형: 세로 x70 y450 w810 h610, 가로 x330 y375 w1190 h385. 더 맞는 사각형이 있으면 새 값을 manifest 에.
- 침대·책장·책상이 바닥 칸을 침범하면 막을 칸(가로 0~11, 세로 0~7) 목록을 함께.

### 2.3 가구 4종 정리판 (필수)
예전 가구 그림을 다시 쓰기로 했습니다(사용자 결정). 같은 디자인을 유지하되 게임 칸에 맞게 정리해 주세요.

| 용도(코드) | 지금 그림 | 요청 |
|---|---|---|
| 쉼터 `rest` | 쿠션·담요 매트 | 바닥에 깔리는 매트. 폰이 위에 올라섬 |
| 이야기 자리 `social` | 클로버 둥근 러그 | 바닥에 깔리는 러그. 폰 여럿이 둘러앉는 느낌 |
| 작업대 `work` | 러그 위 낮은 작업 탁자 | 서 있는 가구. 폰이 탁자 뒤/옆에 섬 |
| 장애물 `wall` | 꽃 화분 상자 | 한 칸을 막는 물건 |

- 각 PNG 투명 배경, 같은 시점(약 30° 위에서 본 시점, 아늑한 방과 같은 각도), 512px 안팎.
- **바닥 접점(앵커)** 픽셀 좌표를 manifest 에(러그·매트는 중심, 작업대·화분은 앞 바닥 접점).
- 한 칸 = 바닥 사각형 폭/12. 러그는 1.5~2칸, 작업대·화분은 1~1.3칸 폭이 자연스러운지 판단 부탁드립니다.
- 배치 판(작은 칸 미리보기)에서도 알아볼 수 있게 실루엣이 분명하게.

### 2.4 UI 틀 텍스처 맞춤 (선택, 2.1 확정 뒤)
명판(`ui/hud/plate.png`), 독(`ui/dock/bar.png`·버튼 타일), 패널(`ui/panel.png`), 탭(`ui/tab-on/off.png`), 이름표(`ui/label.png`)를 새 배경과 같은 나무·크림 색 온도로. **크기·9-slice 여백은 지금 파일과 같게**(코드 수정 없이 교체되도록). 바꾸지 않아도 되는 것은 "유지"로 회신.

## 3. 지켜야 할 것

1. 폰 얼굴은 플레이어가 그림. 배경·시안에 캐릭터 얼굴을 넣지 않음.
2. 창작 공간(방·폰)보다 UI 가 커지지 않음. 배경 장식이 폰보다 강하지 않게.
3. 세로 9:16·가로 16:9 두 장씩. 두 방 모두.
4. 그림 안 글자 금지.
5. 바닥 칸 판정은 코드가 함. 그림은 표시용(가구는 바닥에 그리지 않음).

## 4. 회신 형식

- DES 번호 문서(MD) + `asset-manifest.json`(크기·SHA-256·바닥 사각형·보호 구역·광원·가구 앵커) + PNG.
- 2.1~2.3 을 먼저, 2.4 는 따로 보내도 됩니다. 새로 그리기 전에 방향 시안(한 장)을 먼저 보내 주시면 사용자 확인 뒤 진행합니다.
