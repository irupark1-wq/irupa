## 4. 김플레이 께 전달 부탁 (OUT-PLAY-002) — 대사팩 형식

지금 코드는 아래 상황 키로 대사를 고릅니다. 같은 키로 주시면 표 하나만 바꿔 바로 반영합니다.

| 상황 키 | 화자 | 지금 임시 예 |
|---|---|---|
| greet_offer / greet_accept | 다가간 폰 / 받은 폰 | "잠깐 시간 있어?" / "응, 말해." |
| decline_busy · decline_tired · decline_distance · decline_alone | 거절한 폰 | "이것만 마저 하고." 등 |
| chat / chat_reply / chat_neutral | 대화 | "오늘은 조용하네." / "그러게." / "응, 이따 봐." |
| help_offer · help_accept · help_decline · help_done | 도움 | "도와줄까?" 등 |
| repair_offer · repair_accept · repair_decline · repair_done | 복구 | "기록은 고쳤어." 등 |
| (신규 요청) credit_check · credit_correct · distance_after_repair · blunt_* | 서운함 확인·정정·거리두기·무뚝뚝 | PO-REQ-001 예시 |

- 각 상황마다 말투 3종(warm 다정 / plain 보통 / reserved 무뚝뚝)에 2개 이상 변형을 부탁드립니다. 말투가 의미 없는 상황은 공통 1종이면 됩니다.
- 발화 조건과 금지 조건을 함께 적어 주세요(예: "사유 미확인일 때 '일부러'라는 말 금지").
- 길이: 폰 화면에서 한 줄로 읽히려면 **한국어 16자 이내를 권장**합니다(최대 폭 170px, 12px 글자). PC 는 220px, 13px 입니다.
- 숫자, 성격 이름, 상대의 속마음은 넣지 않습니다.
