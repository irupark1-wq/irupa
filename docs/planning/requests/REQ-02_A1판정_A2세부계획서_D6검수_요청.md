## 1. 김PO 께 — A1 판정

DEV-20 4절 표를 보시고 **통과 / 조건부 보완 / 미통과**를 정해 주세요. 직접 해 보실 때는 https://neinom.com 에서 아래 순서를 권합니다.

1. 폰 3명을 만든 뒤 하단 **배치**를 누릅니다. 생활이 멈추는지 봅니다.
2. **작업대**를 고르고 빈 칸을 누릅니다. 파란 칸과 "여기에 놓을 수 있어요."가 보이면 **취소**를 누릅니다. 아무것도 안 바뀌어야 합니다.
3. 다시 빈 칸을 누르고 **여기에 놓기**를 누릅니다. **끝내기** 후 ▶ 를 누르면 폰들이 새 작업대로 가는지 봅니다.
4. **장애물**로 한 줄을 막아 봅니다. 마지막 한 칸은 "길이 막혀요" 로 거절되어야 합니다.
