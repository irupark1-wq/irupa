## 5. 다음에 할 일

1. 사용자에게서 **기존 GitHub Pages 저장소 주소 + 저장소 한정 PAT**, **기존 Supabase URL + publishable key** 받기. 받으면 `CLAUDE.md` "계정" 절과 `AGENTS.md`·`README.md` 갱신. 저장소는 `git clone` 으로 받아 기존 이력 위에 이 폴더 파일을 덮어쓴다(이 폴더에는 .git 이 없다). Supabase 에 이전 개발자가 만든 테이블·함수가 있는지 사용자에게 SQL Editor 로 확인 요청(`select table_name from information_schema.tables where table_name like 'game1_%'`).
2. **GitHub Pages 배포**: ① `index.html` 의 `/style.css`, `/assets/...` 등 절대 경로 37곳과 `life-ui.js`(`const A = "/assets/"` 포함 5곳)·`app.js`(2곳)의 `"/assets/"` 를 상대 경로(`./`)로 ② `prototype/.nojekyll` ③ `.github/workflows/pages.yml`(actions/upload-pages-artifact 로 `prototype/` 업로드, actions/deploy-pages; Action 은 commit SHA 고정 — AGENTS 보안 기준 8) ④ `git init` → 원격 추가 → push ⑤ 배포 주소에서 PC·폰 확인, 스크린샷 보고. 로컬 서버(`scripts/game1_prototype_server.mjs`)는 호스트를 127.0.0.1 로 제한하고 CSP 를 붙이므로 Pages 와 동작이 다를 수 있다(Pages 는 CSP 없음 → 필요하면 `<meta http-equiv="Content-Security-Policy">` 추가).
3. 디자이너 대기 항목: 글꼴 이름(없으면 나눔스퀘어라운드 woff2 를 `assets/fonts/` 에 넣고 `style.css` 상단 @font-face 주석 해제 + 서버 mime 에 `.woff2`), 참고 예시 캐릭터 6레이어(선택).
4. 다음 디자인 라운드: 폰 만들기·성격·관계 전체 창 시안 요청(케이티정 형식으로 v1.6).
