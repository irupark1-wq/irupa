## 1. A1-10 폰 가로 편집 (PO-DEC-005 §2)

- 배치 패널에 **칸 판**(12×8 버튼)을 넣었습니다. 칸 하나를 누르는 것은 바닥 칸을 누르는 것과 같은 미리보기·판정·확정입니다(새 판정 없음).
- **폰 가로(높이 520px 이하)**: 배치하는 동안 칸 판을 왼쪽 바닥 자리에 크게(칸 24~32px, 812×375 에서 32px) 띄우고, 패널은 가구 2×2 로 좁히고, 하단 독은 잠시 숨깁니다("끝내기"는 패널 안). 편집 중 확대안입니다.
- **세로·PC**: 칸 판은 패널 안에 접혀 있고, 바닥 줄이 24px 보다 낮을 때만 자동으로 펼쳐집니다. 칸 번호 입력도 그대로 있습니다.
- 확인(812×375): 놓을 수 있는 칸(초록 테두리 + "여기에 놓을 수 있어요"), 막힌 칸(빨강 + 이유, 확정 버튼 꺼짐), 확정 후 저장(layout_version +1) — 증거 `docs/evidence/a1-10/`.
- 함께 고친 버그: 확정 버튼을 누르면 장면 상자가 포커스 때문에 40×22px 밀리던 문제(`#scene` 스크롤 금지).
- A1-12(디자이너 축소·가림 판정)는 그대로 남아 있습니다.

## 2. 로그인 구현 (PO-AUTH-001 §2·§3·§6)

| 항목 | 구현 |
|---|---|
| 인증 | Supabase Auth(이 게임 전용 프로젝트). 게임은 비밀번호를 저장·검사하지 않습니다 |
| 라이브러리 | `@supabase/supabase-js` 2.117.2(MIT, npm 무결성 일치 확인)를 레포 안에 고정. 로그인 기능을 쓸 때만 내려받습니다 |
| Google | "Google로 계속하기" → Google → Supabase 콜백 → `/auth/` → 게임. 취소는 "로그인을 취소했어요"(실패 연출 없음) |
| 이메일 | 이메일+비밀번호 가입(확인 메일 필수), 로그인, 확인 메일 재발송, 비밀번호 재설정 메일, 로그인 중 비밀번호 정하기/바꾸기(Google 사용자도 비밀번호 추가 가능, 오래된 로그인이면 재로그인 안내) |
| 실패 문구 | 계정이 없는 경우와 비밀번호가 틀린 경우가 같은 문구. 재설정은 계정 유무와 관계없이 같은 문구. 이미 가입한 주소로 가입하면 "메일이 오지 않으면 이미 가입한 주소일 수 있어요"(메일이 항상 온다고 말하지 않음) |
| 비밀번호 규칙 | 10자 이상, 영문 소문자·대문자·숫자(기기에서 먼저 확인, 서버가 다시 확인). 유출 비밀번호 차단은 Free 라 **사용 안 함** |
| 화면 | 더보기 → 계정. **로그인 상태**와 **월드 저장 위치**를 두 줄로 따로. 로그인 성공 문구는 "월드는 아직 이 기기에만 저장돼 있어요" |
| 진행 중 | 같은 버튼 중복 요청 차단, 로그인·저장 동작 전에 생활 정지(자동 재개 없음) |
| 세션 만료 | 사용자가 누르지 않은 로그아웃은 "다시 로그인이 필요해요"(로컬 월드 그대로) |
| 로그아웃 | 이 기기 로그인만 끝냄(서버 자료·로컬 월드 그대로). 다른 계정의 연결 기록은 이 기기에서 지움 |
| 복귀 페이지 | `/auth/` — 코드를 세션으로 바꾸고 결과 키만 게임에 전달(주소에 토큰·코드를 남기지 않음). 재설정 링크면 새 비밀번호 화면. 다른 브라우저에서 메일 링크를 열면 "이 브라우저에서는 마칠 수 없었어요…" 안내 |
| 보안 정책 | CSP `connect-src` 에 이 프로젝트 Supabase 주소 하나만 추가. 공개용 키만 코드에 있음(비밀 키 없음, 저장소 비밀값 검사 통과) |

공개 설정 확인(공개용 키로 조회): Google 켬, 이메일 켬(확인 필수), 익명 꺼짐, 다른 로그인 방식 없음.
