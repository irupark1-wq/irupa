## 6. 증거·릴리즈 판정 양식

```text
TEST-ID / 요구·SCR·CT·DEC / 작업ID / 상태
코드commit / content·rule·schema version:
환경: 기기/브라우저/DB/네트워크/역할
입력fixture / 명령 / 재현순서:
기대결과 / 실제결과 / 허용·거부검사:
증거파일: 로그(비밀제외)/응답검사/스크린샷/영상
알려진실패 / 수정 / 재검증 / 담당:
```

문서반영≠implemented, 코드존재≠verified. 치명적인 권한누출/중복보상/상태손상은 출시차단. 외부알파에는 MFA/필수CI/복원시험/개인정보/신고운영/성능실측 증거가 필요하다. 원본QA미수령/다중목적맵미완료는 미완료로 남긴다.
